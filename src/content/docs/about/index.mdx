# Cosmos Order

Cosmos Order 是一個**古典醫學理論重建平台**。我們希望把散落在經典、診法、經絡、藥物、經方與運氣中的規則重新接回同一套可理解、可檢查、可持續修正的知識結構。

## 創建者

> **姜智昂 / Shaang Chiang**  
> 獨立古中醫研究學者 · Cosmos Order Founder & Researcher

## 為什麼開始

作者本人在 2017／2018 年短暫的創業項目——十四萬條名老中醫所訓練的大數據型中醫大腦——結束後，才發現到一件事。

現代中醫療效不彰，是因為這幾百年來，對古中醫的誤解，在「師心自用」的情況下，不知不覺中，切斷了與幾千年前的中醫本質的臍帶。

但另一方面，與自己的中醫顧問，又見證了在古中醫的理論上衍生的臨床療效。

因此，這九年來，作者的工作是搜集和尋找內難甲乙桂林等經典背後的本質模型，以便還給千年前老祖宗及它們智慧一個公道和真相。

藉此，也感謝幾位堅守於古中醫的老師們的教誨：潘曉川教授、樊佳如先生（筆名：假如明天來臨）、文碩老師、路輝老師。
