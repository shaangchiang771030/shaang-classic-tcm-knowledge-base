## なぜ Cosmos Order をつくるのか

古典医学には、陰陽、五行、三陰三陽、六気、経絡、五味、脈、方、時令など、一見すると別々に見える多くの言語体系が残されています。Cosmos Order の仕事は、手に入りやすい中医学の一般知識をもう一度並べることではありません。原典と構造へ戻り、それらの体系の背後に、繰り返し検査できるより深い秩序が共有されているのかを問い直します。

「天体周期と円運動が、複数の古典モデルに共通する源となっているのか」という問いは、私たちにとって重要な**研究命題**です。あらかじめ確立した科学的事実として扱うのではなく、文献、モデル、反例、データによってどこまで成立するかを検証します。

## Cosmos Order の研究方法

**観察 → 抽象化 → モデル化 → 交差検証 → 反例 → 応用。**

結論だけを覚えるのではなく、古典知識がどのように導かれ、どこに不確実性が残り、そのモデルが実際の人体や生活へどう戻るのかを理解することを目指します。
