## 為什麼建立 Cosmos Order

古典醫學留下了大量看似分散的語言：陰陽、五行、三陰三陽、六氣、經絡、五味、脈、方與時令。Cosmos Order 的工作不是再傳播一次容易取得的中醫常識，而是回到原典與結構，追問這些體系之間是否共享更深層、可反覆檢查的秩序。

我們把「天體週期與圓周運動是否構成多套古典模型的共同源頭」視為一條核心研究命題，而不是預先宣告的科學結論；文本、模型、反例與資料驗證會逐步決定它能走多遠。

## Cosmos Order 的研究方向

**觀察 → 抽象 → 建模 → 交叉驗證 → 反例 → 應用。**  我們希望讀者不只記住結論，而能逐步掌握古典知識如何被推導、在哪些地方仍有不確定性，以及它如何回到真實的人體與生活。
