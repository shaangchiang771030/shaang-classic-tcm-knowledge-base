# Cosmos Order

Cosmos Order 是一个**古典医学理论整合平台**。我们希望以具有千古历史的经典为主，整理散落在知识、诊法、经络、药物、经方与五运六气中的规则。

利用**以经解经**的精神，作为老祖宗智慧的忠实翻译者，以便在这个因科技发展而动荡不安的年代，给予群众们安身立命之本。

我们希望利用简洁文字，保留老祖宗的用语，但又贴近现代人相对能接受的形式，为古中医正本清源，还给老祖宗们当年的苦心一个公道。

## 为什么开始

作者本人在 2017／2018 年短暂的创业项目——十四万条名老中医资料所训练的大数据型中医大脑——结束后，才发现到一件事。

现代中医疗效不彰，是因为这百年来，对古中医的误解，在“师心自用”的情况下，不知不觉中切断了与几千年前中医本质的脐带。

但另一方面，与自己的中医顾问，又见证了在古中医理论上衍生的临床疗效。

因此，这九年来，作者的工作是搜集和寻找《内经》《难经》《甲乙经》、桂林古本等经典背后的本质模型，以便还给千年前老祖宗及其智慧一个公道和真相。

借此，也感谢几位坚守于古中医的老师们的无私教诲：潘晓川教授、樊佳如先生（笔名：假如明天来临）、文硕老师、路辉老师。
