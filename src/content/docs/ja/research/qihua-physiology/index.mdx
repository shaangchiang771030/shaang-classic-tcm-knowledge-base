# 気化生理

疾病を論じる前に、升降・出入・清濁・水火・臓腑・経絡・営衛を統合した正常人体モデルを再構成する。

<div class="cosmos-curve"><strong>認知曲線</strong><br />一気 → 陰陽升降 → 中土 → 臓腑 → 経絡 → 六経 → 営衛 → 病理</div>

## 領域ガイド

<div class="cosmos-guide-preview">古典医学を病名や弁証から学び始めると、正常な人体が本来どのように動いているのかが見えにくくなります。『気化生理』は、一気の分化から升降出入、中土、臓腑、経絡、六経、営衛へと、正常人体を一段ずつ組み立て直します。</div>

### 疾病を語る前に、まず「動く人体」を組み立て直す

現代人が中医学へ入るとき、肝火・脾虚・腎陽虚、あるいは六経弁証など、疾病側から学び始めることが少なくありません。しかし古典医学にはその前に、もっと基本的な問いがあります。**正常な人は本来どのように運転しているのか。**

『気化生理』が再構成するのは、五臓六腑を静止した解剖図として並べることではありません。升降、出入、清濁分化、水火交通、生長収蔵、内外交換が絶えず続く動的な人体です。したがって読書順序も、臓器暗記ではなく、最小の気化原理から人体を一段ずつ生成するように組みます。

入口の [『医者の理法理解と天人の気化総綱』](/ja/qihua_physiology_concept/01-醫者明理與天人氣化總綱/) は医者が天時・運気・虚実・順逆をなぜ理解すべきかを置き、[『一気・陰陽・清濁と中気の枢軸』](/ja/qihua_physiology_concept/02-一氣陰陽清濁與中氣樞軸/) で一気が陰陽・清濁へ分化し、中気が升降をつなぐ枢となる最初のモデルを作ります。[『四象・五行と春夏秋冬のリズム』](/ja/qihua_physiology_concept/03-四象五行與春夏秋冬節律/) はその陰陽を春夏秋冬の生長化収蔵へ展開します。続く [『脾胃の中土と人体五行の生成』](/ja/qihua_physiology_concept/04-脾胃中土與人體五行生成/) では脾胃中土を人体の中央枢軸へ落とし、[『探源図解と天地人の気化総図』](/ja/qihua_physiology_concept/05-探源圖解與天地人氣化總圖/) で天地人を一枚の気化総図へ戻します。[『水火の徴候と上下左右の経路』](/ja/qihua_physiology_concept/07-水火徵兆與上下左右道路/) は水火・上下左右という抽象語を観察できる徴候へ近づけ、[『生長化収蔵と五臓・情志のリズム』](/ja/qihua_physiology_concept/08-生長收藏與五臟情志節律/) は四時の生長収蔵を五臓と情志のリズムへ接続します。

人体は外界から孤立していないため、次は年間環境を作ります。[『六気主時と年間気候の分節』](/ja/qihua_physiology_concept/09-六氣主時與年度氣候分段/) で六気主時の基線、[『司天・在泉と上半期・下半期の気候』](/ja/qihua_physiology_concept/10-司天在泉與上下半年氣候/) で司天・在泉による上下半年の背景、[『天符・歳会・太乙天符と運気の重ね合わせ』](/ja/qihua_physiology_concept/11-天符歲會太乙天符與運氣疊加/) で天符・歳会・太乙天符など複数条件が重なる場面を扱います。ここでも順序は「まず基線、次に重ね合わせ」です。

天地の時間枠ができた後に、[『人生の始まりと祖気の形成』](/ja/qihua_physiology_concept/12-人生之始與祖氣成形/) で一人の生命が祖気から形をなしていく過程へ戻ります。そこから [『五臓六腑の機能ネットワーク総論』](/ja/qihua_physiology_concept/13-五臟六腑功能網路總論/) が五臓六腑を孤立器官ではなく機能ネットワークとして総覧し、[『脾胃中央の運化と太倉の輸布』](/ja/qihua_physiology_concept/16-脾胃中央運化與太倉輸布/) で中央の脾胃、[『肝胆の風木・謀慮と中正の決断』](/ja/qihua_physiology_concept/15-肝膽風木謀慮與中正決斷/) で肝胆の風木と条達、[『心・小腸の君火、神明と化物生血』](/ja/qihua_physiology_concept/14-心與小腸君火神明與化物生血/) で心・小腸の君火と神明・化物生血、[『肺・大腸の制節、宣降と伝導』](/ja/qihua_physiology_concept/17-肺大腸制節宣降與傳導/) で肺・大腸の制節宣降、[『腎・膀胱の水蔵、津液と気化出入』](/ja/qihua_physiology_concept/18-腎膀胱水藏津液與氣化出入/) で腎・膀胱の水蔵と津液出入、[『心包・三焦の相火、臣使と水道膜網』](/ja/qihua_physiology_concept/19-心包三焦相火臣使與水道膜網/) で心包・三焦という全身分布網へ進みます。[『臓腑の部位形象と内外ネットワーク』](/ja/qihua_physiology_concept/20-臟腑部位形象與內外連網/) はこれらの機能を形体・部位へ戻し、気化が身体を離れた抽象論になることを防ぎます。

臓腑ができれば、次は接続です。[『十二経の交接と環のごとき循環』](/ja/qihua_physiology_concept/21-十二經相交與如環無端/) は十二経の循環、[『衝任督帯と先天・後天の交会』](/ja/qihua_physiology_concept/22-衝任督帶與先後天交會/) は衝任督帯による先後天・胞宮・陰陽の交通を加えます。その上で [『六経解と十二経を統べる六気』](/ja/qihua_physiology_concept/23-六經解與十二經由六氣統攝/) を読み、六経を十二経から「六本減らしたもの」ではなく、より上位の統摂層として理解します。[『六経の開闔枢と審証の要点』](/ja/qihua_physiology_concept/29-六經開闔樞與審證大關鍵/) の開闔枢は外達・内収・転枢という運動役割を示し、[『六気解と主令・化気・盛衰』](/ja/qihua_physiology_concept/24-六氣解與主令化氣盛衰/) は風寒暑湿燥火の性質をこの六経動態へ接続します。

気化には空間だけでなく時間尺度があります。[『営気の運行と脈中の日夜五十周』](/ja/qihua_physiology_concept/25-營氣運行與脈中日夜五十周/) は営気の脈中日夜五十周、[『衛気の出入と覚醒・睡眠・防衛リズム』](/ja/qihua_physiology_concept/26-衛氣出入與寤寐防衛節律/) は衛気の出入と覚醒・睡眠・防衛リズム、[『男女の天癸と生命の長周期』](/ja/qihua_physiology_concept/27-男女天癸與生命長周期/) は天癸・腎気・衝任・筋骨・生殖を一生の長周期へ伸ばし、[『血・気・精・神と養生協調の総論』](/ja/qihua_physiology_concept/28-血氣精神與養生協調總論/) は血・気・精・神・経脈・衛気・志意を一つの安定系へ統合します。

ここまで「正常な人」を作って初めて、[『陰陽変化と治病求本』](/ja/qihua_physiology_concept/06-陰陽變化與治病求本/) の「治病必求於本」が単純な寒熱反転ではなくなります。症状の背後で升降が崩れたのか、中気が枢を失ったのか、水火が交通しないのか、臓腑ネットワークか六経開闔枢か、外部六気と個体基線の不整合かを問い直せます。最後の [『本標中気と外感病機の統合』](/ja/qihua_physiology_concept/30-本標中氣與外感病機整合/) は本・標・中気・六経・伏気・暑湿・外感を、正常気化が偏った後の病理として統合します。

この三十篇を終えたとき、目標は五臓五行を暗記することではありません。頭の中で**升る・降る・出る・入る人体モデルを実際に動かし**、どの環節から正常秩序が偏り始めたかを追えるようになることです。
