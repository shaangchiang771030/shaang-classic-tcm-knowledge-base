開闔樞把六經由「六個名稱」轉化成六種動態功能。開主外出與布散，闔主內入與收納，樞主內外之間的轉換。三陽之中，太陽為開、陽明為闔、少陽為樞；三陰之中，太陰為開、厥陰為闔、少陰為樞。太陽上行外達皮毛，陽明內行下達，少陽掌內外出入；太陰布散氣血津液，厥陰收藏上下焦陰血，少陰則在陰經內部完成轉樞。因此開闔樞的重點不是靜態部位，而是判斷氣機究竟卡在「開不出去、闔不進來，還是樞轉不利」。
開闔樞,  若沒有實際的圖形, 會很難想像.
西方發現到的「生命之花與雙渦流環面」的交疊網格，在幾何學上確實只需要 2 到 3 個極其簡單的幾何公理與尺規規則即可自組織演化生成。
它呈現的樣子, 就是個立體動態的陰陽太極體.

| 太陽開 | 最外球面、離心發散 |
| 陽明闔 | 向內漏斗、向心沉降 |

| 太陰開 | 白魚眼向外輻射 |
| 厥陰闔 | 黑魚眼／最深奇點 |
| 少陰樞 | 垂直中軸水火柱 |

有了這幾何對照, 以下的四句, 就好理解了
帝曰：陽明何謂也？岐伯曰：兩陽合明也。
帝曰：厥陰何也？岐伯曰：兩陰交盡也。

另外, 從開闔樞再往桂林古本或傷寒鈐法的經方變化的數量來看, 也確實是按照開 > 闔 > 樞的比例, 相信不是巧合.

## 《醫學探源》原文
「開闔者，如戶之扉；樞者，扉之轉樞也。捨樞不能開闔，捨開闔不能轉樞。是以三經者，不得相失也。開主外出，闔主內入，樞主內外之間。太陽膀胱，氣化上行，外達充於皮毛，以衛外而為固。故太陽主開。……陽明胃經主納水谷……其氣化主於內行下達。故陽明主闔。……少陽三焦，內主膈膜，外主腠理，內外出入之氣，均從腠理往來。……三陽之氣，開闔於形身之內外；三陰之氣，開闔於內之前後上下。……凡血脈之周流，津液之四達，皆由太陰司之。故曰太陰為開也。……厥陰為闔者，足厥陰肝經主藏下焦之陰氣……手厥陰心包絡主藏上焦之陰氣……少陰為樞者，手少陰心經內合包絡，下生脾土……足少陰腎經上濟肺金，下生肝木……此數者，為審證施治之大關鍵，不可不詳究也。」
