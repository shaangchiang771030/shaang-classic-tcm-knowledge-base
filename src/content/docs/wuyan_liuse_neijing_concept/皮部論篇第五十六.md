# 皮部論篇第五十六

<span class="model-tag">[十二－空間]</span>
<span class="model-tag">[陰陽－空間／人體]</span>

黃帝問曰：余聞皮有分部，脈有經紀，筋有結絡，骨有度量，其所生病各異。別其分部，左右<span class="c-yang">上</span><span class="c-yin">下</span>，<span class="c-yin">陰</span><span class="c-yang">陽</span>所在，病之始終，願聞其道。

岐伯對曰：欲知皮部以經脈為紀者，諸經皆然。

<span class="model-tag">[三陰三陽－空間／人體｜六經皮部]</span>
<span class="model-tag">[五行－空間／人體｜五色]</span>

<span class="model-map"><span class="c-yangming">陽明</span>之<span class="c-yang">陽</span>，名曰害蜚，<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中有浮絡者，皆<span class="c-yangming">陽明</span>之絡也。其色多<span class="c-wood">青</span>則<span class="c-wood">痛</span>，多<span class="c-water">黑</span>則<span class="c-water">痹</span>，<span class="c-earth">黃</span><span class="c-fire">赤</span>則<span class="c-hot">熱</span>，多<span class="c-metal">白</span>則<span class="c-cold">寒</span>，五色皆見，則<span class="c-cold">寒</span><span class="c-hot">熱</span>也。絡盛則入客於經。<span class="c-yang">陽主外</span>，<span class="c-yin">陰主內</span>。</span>

<span class="model-tag">[三陰三陽－空間／人體]</span>
<span class="model-tag">[陰陽－空間／人體]</span>

<span class="c-shaoyang">少陽</span>之<span class="c-yang">陽</span>，名曰樞持。<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中，有浮絡者，皆<span class="c-shaoyang">少陽</span>之絡也。絡盛則入客於經，故在<span class="c-yang">陽</span>者主<span class="c-yin">內</span>，在<span class="c-yin">陰</span>者主出，以滲於<span class="c-yin">內</span>，諸經皆然。

<span class="c-taiyang">太陽</span>之<span class="c-yang">陽</span>，名曰關樞。<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中，有浮絡者，皆<span class="c-taiyang">太陽</span>之絡也。絡盛則入客於經。

<span class="c-shaoyin">少陰</span>之<span class="c-yin">陰</span>，名曰樞儒。<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中，有浮絡者，皆<span class="c-shaoyin">少陰</span>之絡也。絡盛則入客於經，其入經也，從<span class="c-yang">陽部</span>注於經，其出者，從<span class="c-yin">陰內</span>注於骨。

<span class="c-jueyin">心主之陰</span>，名曰害肩。<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中，有浮絡者，皆<span class="c-jueyin">心主</span>之絡也。絡盛則入客於經。

<span class="c-taiyin">太陰</span>之<span class="c-yin">陰</span>，名曰關蟄。<span class="c-yang">上</span><span class="c-yin">下</span>同法，視其部中，有浮絡者，皆<span class="c-taiyin">太陰</span>之絡也。絡盛則入客於經。

<span class="model-tag">[十二－空間｜十二經皮部]</span>

<span class="model-map">凡十二經絡脈者，皮之部也。</span>

<span class="model-tag">[陰陽－空間／人體｜由外入內]</span>

<span class="model-map">是故百病之始生也，必先於<span class="c-yang">皮毛</span>。邪中之，則腠理開，開則入客於絡脈，留而不去，傳入於經，留而不去，傳入於<span class="c-yin">腑</span>，廩於<span class="c-yin">腸胃</span>。</span>

<span class="model-tag">[六淫－空間]</span>

邪之始入於<span class="c-yang">皮</span>也，泝然起毫毛，開腠理，其入於絡也，則絡脈盛色變；其入客於經也，則感虛，乃陷下，其留於筋骨之間。<span class="c-cold">寒</span>多則<span class="c-cold">筋攣骨痛</span>；<span class="c-hot">熱</span>多則<span class="c-hot">筋弛骨消，肉爍（月囷）破，毛直而敗</span>。

帝曰：夫子言皮之十二部，其生病皆何如。

<span class="model-tag">[陰陽－空間／人體｜由外入內]</span>

<span class="model-map">岐伯曰：皮者，脈之部也。邪客於<span class="c-yang">皮</span>，則腠理開，開則邪入客於絡脈，絡脈滿，則注於經脈，經脈滿，則入捨於<span class="c-yin">腑臟</span>也。故皮者有分部不與而生大病也。</span>

帝曰：善。
