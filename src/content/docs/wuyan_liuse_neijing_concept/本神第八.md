<span class="model-tag">[陰陽－空間／人體｜五臟藏神]</span>
<div class="model-map">黃帝問於岐伯曰：凡刺之法，先必本於神。血、脈、營、氣、精神，此<span class="c-yin">五臟</span>之所藏也。至其淫泆離臟則精失、魂魄飛揚、志意恍亂、智慮去身者，何因而然乎？天之罪與？人之過乎？何謂德、氣、生、精、神、魂、魄、心、意、志、思、智、慮？請問其故。</div>

<span class="model-tag">[陰陽－空間／天地｜天德地氣]</span>
<div class="model-map">岐伯答曰：<span class="c-yang">天</span>之在我者德也，<span class="c-yin">地</span>之在我者氣也。德流氣薄而生者也。故生之來謂之精；兩精相搏謂之神；隨神往來者謂之魂；並精而出入者謂之魄；所以任物者謂之心；心有所憶謂之意；意之所存謂之志；因志而存變謂之思；因思而遠慕謂之慮；因慮而處物謂之智。</div>

<span class="model-tag">[四象－時間／年尺度｜四時寒暑]</span>
<span class="model-tag">[陰陽－人體調節｜陰陽剛柔]</span>
<div class="model-map">故智者之養生也，必順四時而適<span class="c-cold">寒</span><span class="c-hot">暑</span>，和喜怒而安居處，節<span class="c-yin">陰</span><span class="c-yang">陽</span>而調<span class="c-yang">剛</span><span class="c-yin">柔</span>。如是，則僻邪不至，長生久視。</div>

是故怵惕思慮者則傷神，神傷則恐懼流淫而不止。因悲哀動中者，竭絕而失生。喜樂者，神憚散而不藏。愁憂者，氣閉塞而不行。盛怒者，迷惑而不治。恐懼者，神蕩憚而不收。

<span class="model-tag">[五行－空間／人體｜心神受傷]</span>
<span class="model-tag">[五行－時間／年尺度｜死於所不勝之時]</span>
<div class="model-map"><span class="c-fire">心</span>，<span class="c-fire">怵惕思慮</span>則傷<span class="c-fire">神</span>，<span class="c-fire">神</span>傷則<span class="c-fire">恐懼自失</span>。<span class="c-fire">破（月囷）脫肉，毛悴色夭</span>死於<span class="c-water">冬</span>。</div>

<span class="model-tag">[五行－空間／人體｜脾意受傷]</span>
<span class="model-tag">[五行－時間／年尺度｜死於所不勝之時]</span>
<div class="model-map"><span class="c-earth">脾</span>，<span class="c-earth">愁憂而不解</span>則傷<span class="c-earth">意</span>，<span class="c-earth">意</span>傷則<span class="c-earth">悗亂，四肢不舉，毛悴色夭</span>死於<span class="c-wood">春</span>。</div>

<span class="model-tag">[五行－空間／人體｜肝魂受傷]</span>
<span class="model-tag">[五行－時間／年尺度｜死於所不勝之時]</span>
<div class="model-map"><span class="c-wood">肝</span>，<span class="c-wood">悲哀動中</span>則傷<span class="c-wood">魂</span>，<span class="c-wood">魂</span>傷則<span class="c-wood">狂忘不精</span>，<span class="c-wood">不精則不正</span>，當人<span class="c-wood">陰縮而攣筋，兩脅骨不舉，毛悴色夭</span>死於<span class="c-metal">秋</span>。</div>

<span class="model-tag">[五行－空間／人體｜肺魄受傷]</span>
<span class="model-tag">[五行－時間／年尺度｜死於所不勝之時]</span>
<div class="model-map"><span class="c-metal">肺</span>，<span class="c-metal">喜樂無極</span>則傷<span class="c-metal">魄</span>，<span class="c-metal">魄</span>傷則<span class="c-metal">狂</span>，<span class="c-metal">狂</span>者<span class="c-metal">意不存人</span>，<span class="c-metal">皮革焦，毛悴色夭</span>死於<span class="c-fire">夏</span>。</div>

<span class="model-tag">[五行－空間／人體｜腎志受傷]</span>
<span class="model-tag">[五行－時間／年尺度｜死於所不勝之時]</span>
<div class="model-map"><span class="c-water">腎</span>，<span class="c-water">盛怒而不止</span>則傷<span class="c-water">志</span>，<span class="c-water">志</span>傷則<span class="c-water">喜忘其前言</span>，<span class="c-water">腰脊不可以俛仰屈伸，毛悴色夭</span>死於<span class="c-earth">季夏</span>。</div>

<span class="model-tag">[五行－空間／人體｜精骨腎系]</span>
<span class="model-tag">[陰陽－空間／人體｜陰虛]</span>
<div class="model-map"><span class="c-water">恐懼而不解</span>則傷<span class="c-water">精</span>，<span class="c-water">精</span>傷則<span class="c-water">骨酸痿厥</span>，<span class="c-water">精時自下</span>。是故<span class="c-yin">五臟</span>主藏<span class="c-water">精</span>者也，不可傷，傷則失守而<span class="c-yin">陰虛</span>；<span class="c-yin">陰虛</span>則無氣，無氣則死矣。</div>

是故用針者，察觀病人之態，以知精、神、魂、魄之存亡，得失之意，五者以傷，針不可以治之也。

<span class="model-tag">[五行－空間／人體｜肝藏血・血捨魂]</span>
<div class="model-map"><span class="c-wood">肝</span>藏<span class="c-wood">血</span>，<span class="c-wood">血</span>捨<span class="c-wood">魂</span>，<span class="c-wood">肝</span>氣虛則<span class="c-wood">恐</span>，實則<span class="c-wood">怒</span>。</div>

<span class="model-tag">[五行－空間／人體｜脾藏營・營捨意]</span>
<div class="model-map"><span class="c-earth">脾</span>藏<span class="c-earth">營</span>，<span class="c-earth">營</span>捨<span class="c-earth">意</span>，<span class="c-earth">脾</span>氣虛則<span class="c-earth">四肢不用</span>，<span class="c-earth">五臟不安</span>，實則<span class="c-earth">腹脹經溲不利</span>。</div>

<span class="model-tag">[五行－空間／人體｜心藏脈・脈捨神]</span>
<div class="model-map"><span class="c-fire">心</span>藏<span class="c-fire">脈</span>，<span class="c-fire">脈</span>捨<span class="c-fire">神</span>，<span class="c-fire">心</span>氣虛則<span class="c-fire">悲</span>，實則<span class="c-fire">笑不休</span>。</div>

<span class="model-tag">[五行－空間／人體｜肺藏氣・氣捨魄]</span>
<div class="model-map"><span class="c-metal">肺</span>藏<span class="c-metal">氣</span>，<span class="c-metal">氣</span>捨<span class="c-metal">魄</span>，<span class="c-metal">肺</span><span class="c-metal">氣</span>虛，則<span class="c-metal">鼻塞不利少氣</span>，實則<span class="c-metal">喘喝胸盈仰息</span>。</div>

<span class="model-tag">[五行－空間／人體｜腎藏精・精捨志]</span>
<div class="model-map"><span class="c-water">腎</span>藏<span class="c-water">精</span>，<span class="c-water">精</span>捨<span class="c-water">志</span>，<span class="c-water">腎</span>氣虛則<span class="c-water">厥</span>，實則<span class="c-water">脹</span>。五臟不安。必審五臟之病形，以知其氣之虛實，謹而調之也。</div>
