<span class="model-tag">[五行－空間／人體｜邪在肺]</span>
<div class="model-map">邪在<span class="c-metal">肺</span>，則病<span class="c-metal">皮膚痛</span>，<span class="c-metal">寒熱</span>，<span class="c-metal">上氣喘</span>，<span class="c-metal">汗出</span>，<span class="c-metal">欬動肩背</span>。取之膺中外喻，背三節五臟之傍，以手疾按之，快然，乃刺之。取之缺盆中以越之。</div>

<span class="model-tag">[五行－空間／人體｜邪在肝]</span>
<div class="model-map">邪在<span class="c-wood">肝</span>，則<span class="c-wood">兩脅中痛</span>，<span class="c-wood">寒中</span>，<span class="c-wood">惡血在內</span>，<span class="c-wood">行善掣節</span>，<span class="c-wood">時腳腫</span>。取之行間，以引脅下，補三里以溫胃中，取血脈以散惡血；取耳間青脈，以去其掣。</div>

<span class="model-tag">[五行－空間／人體｜邪在脾胃]</span>
<span class="model-tag">[陰陽－空間／人體｜有餘不足]</span>
<div class="model-map">邪在<span class="c-earth">脾胃</span>，則病<span class="c-earth">肌肉痛</span>，<span class="c-yang">陽氣有餘</span>，<span class="c-yin">陰氣不足</span>，則<span class="c-hot">熱中善飢</span>；<span class="c-yang">陽氣不足</span>，<span class="c-yin">陰氣有餘</span>，則<span class="c-cold">寒中腸鳴、腹痛</span>；<span class="c-yin">陰</span><span class="c-yang">陽</span>俱有餘，若俱不足，則有<span class="c-cold">寒</span>有<span class="c-hot">熱</span>，皆調於三里。</div>

<span class="model-tag">[五行－空間／人體｜邪在腎]</span>
<div class="model-map">邪在<span class="c-water">腎</span>，則病<span class="c-water">骨痛</span>，<span class="c-yin">陰</span><span class="c-water">痹</span>。<span class="c-yin">陰</span><span class="c-water">痹</span>者，按之而不得，<span class="c-water">腹脹</span>，<span class="c-water">腰痛</span>，<span class="c-water">大便難</span>，<span class="c-water">肩背頸項痛</span>，<span class="c-water">時眩</span>。取之湧泉、崑崙。視有血者，盡取之。</div>

<span class="model-tag">[五行－空間／人體｜邪在心]</span>
<div class="model-map">邪在<span class="c-fire">心</span>，則病<span class="c-fire">心痛</span>，<span class="c-fire">喜悲時眩僕</span>；視有餘不足而調之其輸也。</div>
