# Cosmos Order

Cosmos Order は、**古典医学の理論体系を統合するための研究プラットフォーム**です。数千年の歴史をもつ古典を主な基盤とし、診法、経絡、薬物、経方、五運六気などに分散して残されている知識と規則を整理することを目指しています。

私たちは、**「経をもって経を解く」**という精神を重視し、先人の知恵を忠実に現代へ伝える翻訳者でありたいと考えています。技術の急速な発展によって社会が大きく揺れ動く時代に、人々が自らの拠り所を考えるための一つの基盤を提供したいという思いがあります。

文章はできる限り簡潔にしながら、古典に残された用語を尊重し、同時に現代の読者が比較的受け入れやすい形で提示します。古典中国医学の源流を整理し直し、先人たちが積み重ねた思考に対して公正な理解を取り戻すことが目的です。

## なぜ始めたのか

2017／2018 年、著名な老中医の十四万件のデータを用いて訓練したビッグデータ型「中医大脳」の短期スタートアップ・プロジェクトを終えた後、著者は一つの問題に気づきました。

著者の見解では、現代中医学で十分な治療効果が得られないことがある背景には、この百年間に蓄積された古典医学への誤解があります。個々の解釈を優先する「師心自用」の積み重ねによって、数千年前の中国医学がもっていた本質的な構造とのつながりが、知らず知らずのうちに断たれてきたのではないかと考えています。

一方で、自身の中医学顧問とともに、古典医学理論から導かれた臨床的な効果を実際に目にする機会もありました。

そのため、この九年間は『内経』『難経』『鍼灸甲乙経』、桂林古本などの古典の背後にある本質的モデルを収集し、探究することを主な仕事としてきました。数千年前の先人とその知恵に、公正で真実に近い理解を返すことを目指しています。

また、古典中国医学を守り続け、惜しみなく教えてくださった潘曉川教授、樊佳如先生（筆名：假如明天來臨）、文碩先生、路輝先生に感謝します。
