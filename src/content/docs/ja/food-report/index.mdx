# 干支タイミング × 食養生レポート

この機能は現在開発中です。将来は、**個人の時空・体質分析 + 古典食養生規則の研究**を中心に、一回完結型の個人研究レポートを作成する構想です。

現在このページは製品入口の予約ページであり、**出生情報、健康情報、決済情報は収集していません。**

> 将来のレポートは食養生・ウェルネス上の参考および古典モデルの研究体験として位置づけ、医療上の診断や治療助言を構成するものではありません。
