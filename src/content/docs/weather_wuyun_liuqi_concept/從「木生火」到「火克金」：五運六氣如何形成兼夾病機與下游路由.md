七個運氣場同時作用時，有一種結構特別值得注意：`4+3`。

它代表七個場沒有分散，而是全部聚成兩個強大的五行簇。例如四個場屬火、三個場屬木；或者四個場屬金、三個場屬火。

如果只用「嚴重度」看，兩者都叫 4+3。但《內經》的五行理論會提醒我們：**木與火之間是相生，火與金之間卻是相剋。相同的強度，不代表相同的病機。**

四萬醫案中的實際曆法也證明了這一點。282 個 4+3 病例並不是隨意排列，其中約 **248 例是火4＋木3**，約 **32 例是金4＋火3**。換句話說，真實五運六氣曆法本身已經把可出現的狀態空間限制得很窄。

「木3生火4」的病例中，咳、喘、水腫、嘔吐、煩熱一類症狀較常集中出現，很像一種木火互相助長、病機範圍被同步打開的狀態。這與中醫常說的「風火相煽」很接近：不是先有一個孤立的風證，再加一個火證，而是兩個氣化模態互相增幅。

更值得注意的是「火3克金4」。

如果病機只是停留在靜態五行，我們本來會期待主要看到火、金兩類問題。但實際 Clinical Path 並沒有停在這裡，而是大量落向**水與木**。在最強的一組病例中，約九成可分類病機落到了這兩個下游方向。

這讓我們開始看到一種很像「級聯」的現象：一個五行衝突發生之後，病機不一定停在被作用的第一個臟腑，而會沿生剋網絡往下一站轉移。

但這裡需要保持分寸。我們目前可以說「火克金的場，後續較多出現水、木病機路徑」，卻還不能直接把它翻譯成「肺金一定先損，然後腎水枯，再使肝木失養」。因為醫案中的病機 Path 還沒有完整區分每一站究竟是虛、實、受損還是代償。

即便如此，這已經改變了五運六氣的讀法。

以後看到 `4+3`，不能只寫「共振七級」。我們至少還要問：

**是哪兩行？誰是主簇？誰是次簇？它們是相生還是相剋？病機最後停在哪一站？**

這正好與《內經》反覆談到的「亢害承制」「子母相及」「勝復」相呼應。運氣不是五個靜態格子，而更像一張會傳遞、轉向、補償的病機網絡。

如此理解，五運六氣才真正從曆法知識，回到了臨床辨證。
