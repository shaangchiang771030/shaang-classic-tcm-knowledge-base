# 六微旨大論篇第六十八

黃帝問曰：嗚呼，遠哉！天之道也，如迎浮雲，若視深淵尚可測，迎浮雲莫知其極。夫子數言謹奉天道，余聞而藏之，心私異之，不知其所謂也？願夫子溢志盡言其事，令終不滅，久而不絕，天之道，可得聞乎？  

岐伯稽首再拜對曰：明乎哉問！天之道也，此因天之序，盛衰之時也。  

帝曰：願聞天道六六之節，盛衰何也？  

<span class="model-tag">[三陰三陽－時間／年尺度｜六氣標位・右側循環]</span>

<div class="model-map">
岐伯曰：上下有位，左右有紀。故<span class="c-shaoyang">少陽</span>之右，<span class="c-yangming">陽明</span>治之；<span class="c-yangming">陽明</span>之右，<span class="c-taiyang">太陽</span>治之；<span class="c-taiyang">太陽</span>之右，<span class="c-jueyin">厥陰</span>治之；<span class="c-jueyin">厥陰</span>之右，<span class="c-shaoyin">少陰</span>治之；<span class="c-shaoyin">少陰</span>之右，<span class="c-taiyin">太陰</span>治之；<span class="c-taiyin">太陰</span>之右，<span class="c-shaoyang">少陽</span>治之；此所謂氣之標，蓋南面而待也。故曰：因天之序，盛衰之時，移光定位，正立而待之，此之謂也。  
</div>

<span class="model-tag">[三陰三陽－時間／年尺度｜本・標・中氣]</span>
<span class="model-tag">[六淫－年尺度]</span>

<div class="model-map">
<span class="c-shaoyang">少陽</span>之上，<span class="c-shaoyang">火氣</span>治之，中見<span class="c-jueyin">厥陰</span>。  
<span class="c-yangming">陽明</span>之上，<span class="c-yangming">燥氣</span>治之，中見<span class="c-taiyin">太陰</span>。  
<span class="c-taiyang">太陽</span>之上，<span class="c-taiyang">寒氣</span>治之，中見<span class="c-shaoyin">少陰</span>。  
<span class="c-jueyin">厥陰</span>之上，<span class="c-jueyin">風氣</span>治之，中見<span class="c-shaoyang">少陽</span>。  
<span class="c-shaoyin">少陰</span>之上，<span class="c-shaoyin">熱氣</span>治之，中見<span class="c-taiyang">太陽</span>。  
<span class="c-taiyin">太陰</span>之上，<span class="c-taiyin">濕氣</span>治之，中見<span class="c-yangming">陽明</span>。  
本標不同，氣應異象。  
</div>

<span class="model-tag">[三陰三陽－時間／年尺度｜氣至早晏・太過不及]</span>

<div class="model-map">
帝曰：其有至而至，有至而不至，有至而太過，何也？  
岐伯曰：至而至者和；至而不至，來氣不及也；未至而至，來氣有餘也。  
帝曰：至而不至，未至而至，如何？  
岐伯曰：應則順，否則逆，逆則變生，變則病。  
帝曰：善。請言其應。  
岐伯曰：物生其應也，氣脈其應也。  
</div>

帝曰：善。願聞地理之應六節，氣位，何如？  

<span class="model-tag">[六淫－空間｜地理六節・六步]</span>

<div class="model-map">
岐伯曰：顯明之右，<span class="c-shaoyin">君火</span>之位也。<span class="c-shaoyin">君火</span>之右，退行一步，<span class="c-shaoyang">相火</span>治之。復行一步，<span class="c-earth">土氣</span>治之。復行一步，<span class="c-metal">金氣</span>治之。復行一步，<span class="c-water">水氣</span>治之。復行一步，<span class="c-wood">木氣</span>治之。復行一步，<span class="c-shaoyin">君火</span>治之。  
</div>

<span class="model-tag">[五行－空間（相克）｜亢害承制]</span>

<div class="model-map">
<span class="c-shaoyang">相火</span>之下，<span class="c-water">水氣</span>承之；<span class="c-water">水位</span>之下，<span class="c-earth">土氣</span>承之；<span class="c-earth">土位</span>之下，<span class="c-wood">風氣</span>承之；<span class="c-wood">風位</span>之下，<span class="c-metal">金氣</span>承之；<span class="c-metal">金位</span>之下，<span class="c-fire">火氣</span>承之；<span class="c-shaoyin">君火</span>之下，<span class="c-yin">陰情</span>承之。  

帝曰：何也？  
岐伯曰：亢則害，承乃制。制則生化，外列盛衰；害則敗亂，生化大病。  
</div>

帝曰：盛衰何如？  
岐伯曰：非其位則邪，當其位則正，邪則變甚，正則微。  
帝曰：何謂當位？  

<span class="model-tag">[五行－時間／年尺度｜歲會]</span>

<div class="model-map">
岐伯曰：<span class="c-wood">木運</span>臨<span class="c-wood">卯</span>，<span class="c-fire">火運</span>臨<span class="c-fire">午</span>，<span class="c-earth">土運</span>臨<span class="c-earth">四季</span>，<span class="c-metal">金運</span>臨<span class="c-metal">酉</span>，<span class="c-water">水運</span>臨<span class="c-water">子</span>，所謂歲會，氣之平也。  
</div>

帝曰：非位何如？  
岐伯曰：歲不與會也。  

<span class="model-tag">[五行－時間／年尺度｜天符]</span>
<span class="model-tag">[三陰三陽－時間／年尺度]</span>

<div class="model-map">
帝曰：<span class="c-earth">土運</span>之歲，上見<span class="c-taiyin">太陰</span>；<span class="c-fire">火運</span>之歲，上見<span class="c-shaoyang">少陽</span>，<span class="c-shaoyin">少陰</span>；<span class="c-metal">金運</span>之歲，上見<span class="c-yangming">陽明</span>；<span class="c-wood">木運</span>之歲，上見<span class="c-jueyin">厥陰</span>；<span class="c-water">水運</span>之歲，上見<span class="c-taiyang">太陽</span>；奈何？  
岐伯曰：天之與會也，故天元冊曰天符。  
天符歲會何如？  
岐伯曰：太一天符之會也。  
</div>

<span class="model-tag">[五行－時間／年尺度｜天符・歲會・太一天符]</span>

<div class="model-map">
帝曰：其貴賤何如？  
岐伯曰：天符為執法，歲位為行令，太一天符為貴人。  
帝曰：邪之中也奈何？  
岐伯曰：中執法者，其病速而危；中行令者，其病徐而持；中貴人者，其病暴而死。  
</div>

<span class="model-tag">[六淫－年尺度｜君火・相火位次]</span>

<div class="model-map">
帝曰：位之易也，何如？  
岐伯曰：君位臣則順，臣位君則逆。逆則其病近，其害速；順則其病遠，其害微；所謂二火也。  
</div>

帝曰：善。願聞其步何如？  

<span class="model-tag">[六淫－年尺度｜一步六十度有奇・四歲刻差]</span>

<div class="model-map">
岐伯曰：所謂步者，六十度而有奇。故二十四步積盈百刻而成曰也。  
</div>

帝曰：六氣應五行之變何如？  
岐伯曰：位有終始，氣有初中，上下不同，求之亦異也。  
帝曰：求之奈何？  

<span class="model-tag">[六十甲子｜天干・地支合歲]</span>
<span class="model-tag">[五行－時間／年尺度｜五運化氣]</span>
<span class="model-tag">[三陰三陽－時間／地支每六年｜司天]</span>

<div class="model-map">
岐伯曰：天氣始於<span class="c-earth">甲</span>，地氣始於<span class="c-shaoyin">子</span>，<span class="c-shaoyin">子</span><span class="c-earth">甲</span>相合，命日歲立，謹候其時，氣可與期。  
</div>

帝曰：願聞其歲六氣，始終早晏何如？  

<span class="model-tag">[六淫－年尺度｜歲六氣始終刻差]</span>
<span class="model-tag">[六十甲子]</span>
<span class="model-tag">[五行－時間／年尺度｜五運化氣]</span>
<span class="model-tag">[三陰三陽－時間／地支每六年｜司天]</span>

<div class="model-map">
岐伯曰：明乎哉問也。<span class="c-earth">甲</span><span class="c-shaoyin">子</span>之歲，初之氣，天數始於水下一刻，終於八十七刻半。二之氣，始於八十七刻六分，終於七十五刻。三之氣，始於七十六刻，終於六十二刻半。四之氣，始於六十二刻六分，終於五十刻。五之氣，始於五十一刻，終於三十七刻半。六之氣，始於三十七刻六分，終於二十五刻。所謂初六天之數也。  

<span class="c-metal">乙</span><span class="c-taiyin">丑</span>歲，初之氣，天數始於二十六刻，終於一十二刻半。二之氣，始於一十二刻六分，終於水下百刻。三之氣，始於一刻，終於八十七刻半。四之氣，始於八十七刻六分，終於七十五刻。五之氣，始於七十六刻，終於六十二刻半。六之氣，始於六十二刻六分，終於五十刻。所謂六二天之數也。  

<span class="c-water">丙</span><span class="c-shaoyang">寅</span>歲，初之氣，天數始於五十一刻，終於三十七刻半。二之氣，始於三十七刻六分，終於二十五刻。三之氣，始於二十六刻，終於一十二刻半。四之氣，始於一十二刻六分，終於水下百刻。五之氣，始於一刻，終於八十七刻半。六之氣，始於八十七刻六分，終於七十五刻。所謂六三天之數也。  

<span class="c-wood">丁</span><span class="c-yangming">卯</span>歲，初之氣，天數始於七十六刻，終於六十二刻半。二之氣，始於六十二刻六分，終於五十刻。三之氣，始於五十一刻，終於三十七刻半。四之氣，始於三十七刻六分，終於二十五刻。五之氣，始於二十六刻，終於一十二刻半。六之氣，始於一十二刻六分，刻於下水百刻。所謂六四天之數也。次<span class="c-fire">戊</span><span class="c-taiyang">辰</span>歲初之氣復，始於一刻，常如是無已，周而復始。  
</div>

帝曰：願聞其歲候何如？  

<span class="model-tag">[六淫－年尺度｜歲候刻差循環]</span>

<div class="model-map">
岐伯曰：悉乎哉問也。日行一周，天氣始於一刻。日行再周，天氣始於二十六刻。日行三周，天氣始於五十一刻。日行四周，天氣始於七十六刻。日行五周，天氣復始於一刻，所謂一紀也。  
</div>

<span class="model-tag">[六十甲子｜地支四組歲氣會同]</span>
<span class="model-tag">[五行－時間／年尺度｜地支三合五行局]</span>

<div class="model-map">
是故<span class="c-fire">寅午戌</span>歲氣會同，<span class="c-wood">卯未亥</span>歲氣會同，<span class="c-water">辰申子</span>歲氣會同，<span class="c-metal">巳酉丑</span>歲氣會同，終而復始。  
</div>

帝曰：願聞其用也。  

<span class="model-tag">[陰陽－空間／天地｜氣交]</span>

<div class="model-map">
岐伯曰：言<span class="c-yang">天</span>者求之本，言<span class="c-yin">地</span>者求之位，言人者求之氣交。  
帝曰：何謂氣交？  
岐伯曰：<span class="c-yang">上</span><span class="c-yin">下</span>之位，氣交之中，人之居也。  
故曰：天樞之<span class="c-yang">上</span>，<span class="c-yang">天氣</span>主之；天樞之<span class="c-yin">下</span>，<span class="c-yin">地氣</span>主之；氣交之分，人氣從之，萬物由之，此之謂也。  
</div>

<span class="model-tag">[陰陽－空間／天地｜初・中]</span>

<div class="model-map">
帝曰：何謂初中？  
岐伯曰：初凡三十度而有奇？中氣同法。  
帝曰：初中何也？  
岐伯曰：所以分天地也。  
帝曰：願卒聞之？  
岐伯曰：<span class="c-yin">初</span>者<span class="c-yin">地氣</span>也，<span class="c-yang">中</span>者<span class="c-yang">天氣</span>也。  
</div>

<span class="model-tag">[陰陽－空間／天地｜升降相召]</span>

<div class="model-map">
帝曰：其升降何如？  
岐伯曰：氣之升降，天地之更用也。  
帝曰：願聞其用何如？  
岐伯曰：<span class="c-yang">升已而降，降者謂天</span>；<span class="c-yin">降已而升，升者謂地</span>。  
<span class="c-yang">天氣下降</span>，氣流於<span class="c-yin">地</span>，<span class="c-yin">地氣上升</span>，氣騰於<span class="c-yang">天</span>，故高下相召，升降相因，而變作矣。  
</div>

<span class="model-tag">[六淫－年尺度｜六氣相遘・勝復]</span>

<div class="model-map">
帝曰：善。<span class="c-taiyang">寒</span><span class="c-taiyin">濕</span>相遘，<span class="c-yangming">燥</span><span class="c-shaoyin">熱</span>相臨，<span class="c-jueyin">風</span><span class="c-shaoyang">火</span>相值，其有聞手？  
岐伯曰：氣有勝復，勝復之作，有德有化，有用有變，變則邪氣居之。  
帝曰：何謂邪乎？  
岐伯曰：夫物之生，從於化，物之極，由乎變，變化之相薄，成敗之所由也。  
故氣有往復，用有遲速，四者之有，而化而變，風之來也。  
帝曰：遲速往復，風所由生，而化而變，故因盛衰之變耳。成敗倚伏游乎中，何也？  
岐伯曰：成敗倚伏，生乎動，動而不已，則變作矣。  
帝曰：有期乎？  
岐伯曰：不生不化，靜之期也。  
</div>

<span class="model-tag">[陰陽－空間／天地｜出入・升降]</span>
<span class="model-tag">[五行－時間／年尺度｜生長化收藏]</span>

<div class="model-map">
帝曰：不生化乎？  
岐伯曰：出入廢，則神機化滅；升降息，則氣立孤危。  
故非出入，則無以生、長、壯、老、已；非升降，則無以<span class="c-wood">生</span>、<span class="c-fire">長</span>、<span class="c-earth">化</span>、<span class="c-metal">收</span>、<span class="c-water">藏</span>。  
是以生降出入，無器不有。  
故器者，生化之宇，器散則分之，生化息矣。故無不出入，無不升降。  
</div>

化有小大，期有近遠。  
四者之有而貴常守，反常則災害至矣。  
故曰：無形無患，此之謂也。  
帝曰：善。有不生不化乎？  
岐伯曰：悉乎哉問也？與道合同，惟真人也。  
帝曰：善。
