<span class="model-tag">[五行－空間／人體]</span>
<span class="model-tag">[五行－空間（相克）]</span>

<span class="model-map"><span class="c-fire">心</span>之合<span class="c-fire">脈</span>也，其榮<span class="c-fire">色</span>也，其主<span class="c-water">腎</span>也。  
<span class="c-metal">肺</span>之合<span class="c-metal">皮</span>也，其榮<span class="c-metal">毛</span>也，其主<span class="c-fire">心</span>也。  
<span class="c-wood">肝</span>之合<span class="c-wood">筋</span>也，其榮<span class="c-wood">爪</span>也，其主<span class="c-metal">肺</span>也。  
<span class="c-earth">脾</span>之合<span class="c-earth">肉</span>也，其榮<span class="c-earth">唇</span>也，其主<span class="c-wood">肝</span>也。  
<span class="c-water">腎</span>之合<span class="c-water">骨</span>也，其榮<span class="c-water">發</span>也，其主<span class="c-earth">脾</span>也。</span>

<span class="model-tag">[五行－空間（相克）｜五味所傷]</span>

<span class="model-map">是故多食<span class="c-water">咸</span>，則<span class="c-fire">脈凝泣而變色</span>；多食<span class="c-fire">苦</span>，則<span class="c-metal">皮槁而毛拔</span>；多食<span class="c-metal">辛</span>，則<span class="c-wood">筋急而爪枯</span>；多食<span class="c-wood">酸</span>，則<span class="c-earth">肉胝（月芻）而唇揭</span>；多食<span class="c-earth">甘</span>，則<span class="c-water">骨痛而髮落</span>，此五味之所傷也。</span>

<span class="model-tag">[五行－空間／人體｜五味所合]</span>

<span class="model-map">故<span class="c-fire">心</span>欲<span class="c-fire">苦</span>，<span class="c-metal">肺</span>欲<span class="c-metal">辛</span>，<span class="c-wood">肝</span>欲<span class="c-wood">酸</span>，<span class="c-earth">脾</span>欲<span class="c-earth">甘</span>，<span class="c-water">腎</span>欲<span class="c-water">咸</span>，此五味之所合也。</span>

<span class="model-tag">[五行－空間／人體｜五色・五臟]</span>

五臟之氣，故色見<span class="c-wood">青如草茲</span>者死，<span class="c-earth">黃如枳實</span>者死，<span class="c-water">黑如（火台）</span>者死，<span class="c-fire">赤如衄血</span>者死，<span class="c-metal">白如枯骨</span>者死，此五色之見死也。<span class="c-wood">青如翠羽</span>者生，<span class="c-fire">赤如雞冠</span>者生，<span class="c-earth">黃如蟹腹</span>者生，<span class="c-metal">白如豕膏</span>者生，<span class="c-water">黑如烏羽</span>者生，此五色之見生也。生於<span class="c-fire">心</span>，如以縞裹<span class="c-fire">朱</span>。生於<span class="c-metal">肺</span>，如以縞裹<span class="c-metal">紅</span>。生於<span class="c-wood">肝</span>，如以縞裹<span class="c-wood">紺</span>。生於<span class="c-earth">脾</span>，如以縞裹<span class="c-earth">括樓實</span>。生於<span class="c-water">腎</span>，如以縞裹<span class="c-water">紫</span>。此五臟所生之外榮也。

<span class="model-tag">[五行－空間／人體｜色・味・體]</span>

<span class="model-map">色味當五臟，<span class="c-metal">白</span>當<span class="c-metal">肺</span><span class="c-metal">辛</span>，<span class="c-fire">赤</span>當<span class="c-fire">心</span><span class="c-fire">苦</span>，<span class="c-wood">青</span>當<span class="c-wood">肝</span><span class="c-wood">酸</span>，<span class="c-earth">黃</span>當<span class="c-earth">脾</span><span class="c-earth">甘</span>，<span class="c-water">黑</span>當<span class="c-water">腎</span>鹼。故<span class="c-metal">白</span>當<span class="c-metal">皮</span>，<span class="c-fire">赤</span>當<span class="c-fire">脈</span>，<span class="c-wood">青</span>當<span class="c-wood">筋</span>，<span class="c-earth">黃</span>當<span class="c-earth">肉</span>，<span class="c-water">黑</span>當<span class="c-water">骨</span>。</span>

諸<span class="c-fire">脈</span>者，皆屬於<span class="c-wood">目</span>；諸<span class="c-water">髓</span>者，皆屬於<span class="c-water">腦</span>；諸<span class="c-wood">筋</span>者，皆屬於<span class="c-wood">節</span>；諸血者，皆屬於<span class="c-fire">心</span>；諸氣者，皆屬於<span class="c-metal">肺</span>，此四肢八溪之朝夕也。故人臥血歸於<span class="c-wood">肝</span>，<span class="c-wood">肝</span>受血而能<span class="c-wood">視</span>，足受血而能步，掌受血而能握，指受血而能攝。臥出而<span class="c-wood">風</span>吹之，血凝於膚者為痹，凝於<span class="c-fire">脈</span>者為泣，凝於足者為厥。此三者，血行而不得反其空，故為痹厥也。人有大谷十二分，小溪三百五十四名，少十二俞，此皆衛氣所留止，邪氣之所客也，針石緣而去之。

診病之始，五決為紀。欲知其始，先建其母。所謂五決者，五脈也。

<span class="model-tag">[三陰三陽－空間／人體]</span>
<span class="model-tag">[五行－空間／人體]</span>

<span class="model-map"><span class="c-water">頭痛巔疾，下虛上實</span>，過在足<span class="c-shaoyin">少陰</span><span class="c-taiyang">巨陽</span>，甚則入<span class="c-water">腎</span>。  
<span class="c-wood">徇蒙招尤，目冥耳聾，下實上虛</span>，過在足<span class="c-shaoyang">少陽</span><span class="c-jueyin">厥陰</span>，甚則入<span class="c-wood">肝</span>。  
<span class="c-earth">腹滿（月真）脹，支膈胠脅、下厥上冒</span>，過在足<span class="c-taiyin">太陰</span><span class="c-yangming">陽明</span>。  
<span class="c-metal">咳嗽上氣，厥在胸中</span>，過在手<span class="c-yangming">陽明</span><span class="c-taiyin">太陰</span>。  
<span class="c-fire">心煩頭痛，病在膈中</span>，過在手<span class="c-taiyang">巨陽</span><span class="c-shaoyin">少陰</span>。</span>

夫脈之小大，滑澀浮沈，可以指別。五臟之象，可以類推。五臟相音，可以意識。五色微診，可以目察。能合脈色，可以萬全。

<span class="model-tag">[五行－空間／人體｜五色・五脈]</span>

<span class="c-fire">赤脈</span>之至也，<span class="c-fire">喘而堅</span>。診曰：<span class="c-fire">有積氣在中，時害於食</span>名曰<span class="c-fire">心痹</span>。得之外疾，思慮而<span class="c-fire">心虛</span>，故邪從之。

<span class="c-metal">白脈</span>之至也，<span class="c-metal">喘而浮。上虛下實，驚，有積氣在胸中，喘而虛</span>。名曰<span class="c-metal">肺痹</span>。<span class="c-metal">寒熱</span>，得之醉而使內也。

<span class="c-wood">青脈</span>之至也。<span class="c-wood">長而左右彈。有積氣在心下，肢胠</span>。名曰<span class="c-wood">肝痹</span>。得之<span class="c-water">寒</span><span class="c-earth">濕</span>，與疝同法。<span class="c-wood">腰痛足清頭痛</span>。

<span class="c-earth">黃脈</span>之至也，<span class="c-earth">大而虛。有積氣在腹中，有厥氣</span>，名曰<span class="c-earth">厥疝</span>。<span class="c-earth">女子同法，得之疾使四肢，汗出當</span><span class="c-wood">風</span>。

<span class="c-water">黑脈</span>之至也，<span class="c-water">上堅而大。有積氣在小腹與陰</span>，名曰<span class="c-water">腎痹</span>。<span class="c-water">得之沐浴，清水而臥</span>。

<span class="model-tag">[五行－空間／人體｜五色]</span>

凡相五色之奇脈，面<span class="c-earth">黃</span>目<span class="c-wood">青</span>，面<span class="c-earth">黃</span>目<span class="c-fire">赤</span>，面<span class="c-earth">黃</span>目<span class="c-metal">白</span>，面<span class="c-earth">黃</span>目<span class="c-water">黑</span>者，皆不死也。面<span class="c-wood">青</span>目<span class="c-fire">赤</span>，面<span class="c-fire">赤</span>目<span class="c-metal">白</span>，面<span class="c-wood">青</span>目<span class="c-water">黑</span>，面<span class="c-water">黑</span>目<span class="c-metal">白</span>，面<span class="c-fire">赤</span>目<span class="c-wood">青</span>，皆死也。
