<span class="model-tag">[五行－空間／人體｜五味所入]</span>
<div class="model-map">五味所入：<span class="c-wood">酸</span>入<span class="c-wood">肝</span>、<span class="c-metal">辛</span>入<span class="c-metal">肺</span>、<span class="c-fire">苦</span>入<span class="c-fire">心</span>、<span class="c-water">咸</span>入<span class="c-water">腎</span>、<span class="c-earth">甘</span>入<span class="c-earth">脾</span>，是為五入。</div>
<span class="model-tag">[五行－空間／人體｜臟腑所病]</span>
<div class="model-map">五氣所病：<span class="c-fire">心</span>為<span class="c-fire">噫</span>、<span class="c-metal">肺</span>為<span class="c-metal">咳</span>、<span class="c-wood">肝</span>為<span class="c-wood">語</span>、<span class="c-earth">脾</span>為<span class="c-earth">吞</span>、<span class="c-water">腎</span>為<span class="c-water">欠</span>，為<span class="c-water">嚏</span>，<span class="c-earth">胃</span>為<span class="c-earth">氣逆</span>為<span class="c-earth">噦</span>，為<span class="c-earth">恐</span>，<span class="c-metal">大腸</span><span class="c-fire">小腸</span>為洩，下焦溢為<span class="c-water">水</span>，<span class="c-water">膀胱不利</span>為<span class="c-water">癃</span>，不約為<span class="c-water">遺弱</span>，<span class="c-wood">膽</span>為<span class="c-wood">怒</span>，是為五病。</div>
<span class="model-tag">[五行－空間／人體｜五精所並]</span>
<div class="model-map">五精所並：精氣並於<span class="c-fire">心</span>則<span class="c-fire">善</span>，並於<span class="c-metal">肺</span>則<span class="c-metal">悲</span>，並於<span class="c-wood">肝</span>則<span class="c-wood">憂</span>，並於<span class="c-earth">脾</span>則<span class="c-earth">畏</span>，並於<span class="c-water">腎</span>則<span class="c-water">恐</span>，是謂五並，虛而相並者也。</div>
<span class="model-tag">[五行－空間／人體｜五臟所惡]</span>
<span class="model-tag">[六淫－空間]</span>
<div class="model-map">五臟所惡：<span class="c-fire">心</span>惡<span class="c-hot">熱</span>、<span class="c-metal">肺</span>惡<span class="c-cold">寒</span>、<span class="c-wood">肝</span>惡<span class="c-wood">風</span>、<span class="c-earth">脾</span>惡<span class="c-earth">濕</span>、<span class="c-water">腎</span>惡<span class="c-metal">燥</span>。是謂五惡。</div>
<span class="model-tag">[五行－空間／人體｜五臟化液]</span>
<div class="model-map">五臟化液：<span class="c-fire">心</span>為<span class="c-fire">汗</span>、<span class="c-metal">肺</span>為<span class="c-metal">涕</span>、<span class="c-wood">肝</span>為<span class="c-wood">淚</span>、<span class="c-earth">脾</span>為<span class="c-earth">涎</span>、<span class="c-water">腎</span>為<span class="c-water">唾</span>。是為五液。</div>
<span class="model-tag">[五行－空間／人體｜五味所禁]</span>
<div class="model-map">五味所禁：<span class="c-metal">辛</span>走氣、氣病無多食<span class="c-metal">辛</span>；<span class="c-water">咸</span>走<span class="c-fire">血</span>，<span class="c-fire">血</span>病無多食<span class="c-water">咸</span>；<span class="c-fire">苦</span>走<span class="c-water">骨</span>，<span class="c-water">骨</span>病無多食<span class="c-fire">苦</span>，<span class="c-earth">甘</span>走<span class="c-earth">肉</span>，<span class="c-earth">肉</span>病無多食<span class="c-earth">甘</span>；<span class="c-wood">酸</span>走<span class="c-wood">筋</span>，<span class="c-wood">筋</span>病無多食<span class="c-wood">酸</span>。是謂五禁，無令多食。</div>
<span class="model-tag">[陰陽－空間／人體｜五病所發]</span>
<span class="model-tag">[陰陽－時間／年尺度]</span>
<div class="model-map">五病所發：<span class="c-yin">陰</span>病發於<span class="c-water">骨</span>，<span class="c-yang">陽</span>病發於血，<span class="c-yin">陰</span>病發於<span class="c-earth">肉</span>，<span class="c-yang">陽</span>病發於<span class="c-yinyin">冬</span>；<span class="c-yin">陰</span>病發於<span class="c-yangyang">夏</span>。是謂五發。</div>
<span class="model-tag">[陰陽－空間／人體｜五邪所亂]</span>
<div class="model-map">五邪所亂：邪入於<span class="c-yang">陽</span>則狂，邪入於<span class="c-yin">陰</span>則痹；搏<span class="c-yang">陽</span>則為巔疾，搏<span class="c-yin">陰</span>則為瘖；<span class="c-yang">陽</span>入之<span class="c-yin">陰</span>則靜，<span class="c-yin">陰</span>出之<span class="c-yang">陽</span>則怒。是為五亂。</div>
<span class="model-tag">[五行－時間／年尺度｜四時脈象錯位]</span>
<div class="model-map">五邪所見：<span class="c-wood">春</span>得<span class="c-metal">秋</span>脈，<span class="c-fire">夏</span>得<span class="c-water">冬</span>脈，<span class="c-earth">長夏</span>得<span class="c-wood">春</span>脈，<span class="c-metal">秋</span>得<span class="c-fire">夏</span>脈，<span class="c-water">冬</span>得<span class="c-earth">長夏</span>脈，名曰陰出之陽，病善怒不治。是謂五邪，皆同命死不治。</div>
<span class="model-tag">[五行－空間／人體｜五臟所藏]</span>
<div class="model-map">五臟所藏：<span class="c-fire">心</span>藏<span class="c-fire">神</span>、<span class="c-metal">肺</span>藏<span class="c-metal">魄</span>、<span class="c-wood">肝</span>藏<span class="c-wood">魂</span>、<span class="c-earth">脾</span>藏<span class="c-earth">意</span>、<span class="c-water">腎</span>藏<span class="c-water">志</span>。是謂五臟所藏。</div>
<span class="model-tag">[五行－空間／人體｜五臟所主]</span>
<div class="model-map">五臟所主：<span class="c-fire">心</span>主<span class="c-fire">脈</span>、<span class="c-metal">肺</span>主<span class="c-metal">皮</span>、<span class="c-wood">肝</span>主<span class="c-wood">筋</span>、<span class="c-earth">脾</span>主<span class="c-earth">肉</span>、<span class="c-water">腎</span>主<span class="c-water">骨</span>。是為五臟所主。</div>
<span class="model-tag">[五行－空間／人體｜五勞所傷]</span>
<div class="model-map">五勞所傷：久視傷<span class="c-fire">血</span>、久臥傷<span class="c-metal">氣</span>、久坐傷<span class="c-earth">肉</span>、久立傷<span class="c-water">骨</span>、久行傷<span class="c-wood">筋</span>。是謂五勞所傷。</div>

<div class="model-map">五脈應象：<span class="c-wood">肝</span>脈<span class="c-wood">弦</span>、<span class="c-fire">心</span>脈<span class="c-fire">鈎</span>、<span class="c-earth">脾</span>脈<span class="c-earth">代</span>、<span class="c-metal">肺</span>脈<span class="c-metal">毛</span>、<span class="c-water">腎</span>脈<span class="c-water">石</span>。是謂五臟之脈。</div>
