开阖枢把六经由「六个名称」转化成六种动态功能。开主外出与布散，阖主内入与收纳，枢主内外之间的转换。三阳之中，太阳为开、阳明为阖、少阳为枢；三阴之中，太阴为开、厥阴为阖、少阴为枢。太阳上行外达皮毛，阳明内行下达，少阳掌内外出入；太阴布散气血津液，厥阴收藏上下焦阴血，少阴则在阴经内部完成转枢。因此开阖枢的重点不是静态部位，而是判断气机究竟卡在「开不出去、阖不进来，还是枢转不利」。
开阖枢,  若没有实际的图形, 会很难想像.
西方发现到的「生命之花与双涡流环面」的交叠网格，在几何学上确实只需要 2 到 3 个极其简单的几何公理与尺规规则即可自组织演化生成。
它呈现的样子, 就是个立体动态的阴阳太极体.

![生命之花与双涡流环面示意](/images/qihua_physiology/生命之花.png)

| 六经 | 对应生命之花的图像映射 |
| --- | --- |
| 太阳开 | 最外球面、离心发散 |
| 阳明阖 | 向内漏斗、向心沉降 |
| 少阳枢 | 中腰喉口、S 曲线转折 |
| 太阴开 | 白鱼眼向外辐射 |
| 厥阴阖 | 黑鱼眼／最深奇点 |
| 少阴枢 | 垂直中轴水火柱 |

有了这几何对照, 以下的四句, 就好理解了
帝曰：阳明何谓也？岐伯曰：两阳合明也。
帝曰：厥阴何也？岐伯曰：两阴交尽也。

另外, 从开阖枢再往桂林古本或伤寒钤法的经方变化的数量来看, 也确实是按照开 > 阖 > 枢的比例, 相信不是巧合.

## 《医学探源》原文
「开阖者，如户之扉；枢者，扉之转枢也。舍枢不能开阖，舍开阖不能转枢。是以三经者，不得相失也。开主外出，阖主内入，枢主内外之间。太阳膀胱，气化上行，外达充于皮毛，以卫外而为固。故太阳主开。……阳明胃经主纳水谷……其气化主于内行下达。故阳明主阖。……少阳三焦，内主膈膜，外主腠理，内外出入之气，均从腠理往来。……三阳之气，开阖于形身之内外；三阴之气，开阖于内之前后上下。……凡血脉之周流，津液之四达，皆由太阴司之。故曰太阴为开也。……厥阴为阖者，足厥阴肝经主藏下焦之阴气……手厥阴心包络主藏上焦之阴气……少阴为枢者，手少阴心经内合包络，下生脾土……足少阴肾经上济肺金，下生肝木……此数者，为审证施治之大关键，不可不详究也。」
