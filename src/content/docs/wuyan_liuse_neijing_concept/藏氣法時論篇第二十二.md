黃帝問曰：合人形以法四時五行而治，何如而從，何如而逆？得失之意，願聞其事。

岐伯對曰：五行者，<span class="c-metal">金</span><span class="c-wood">木</span><span class="c-water">水</span><span class="c-fire">火</span><span class="c-earth">土</span>也。更貴更賤，以知死生，以決成敗，而定五臟之氣，間甚之時，死生之期也。

帝曰：願卒聞之。


<span class="model-tag">[五行－時間／年尺度]</span>
<span class="model-tag">[五行－時間／一組天干（十日）為週期]</span>
<span class="model-tag">[三陰三陽－空間／人體]</span>

岐伯曰：<span class="c-wood">肝</span>主<span class="c-wood">春</span>，足<span class="c-jueyin">厥陰</span><span class="c-shaoyang">少陽</span>主治。其日<span class="c-wood">甲乙</span>。<span class="c-wood">肝</span>苦<span class="c-wood">急</span>，急食<span class="c-earth">甘以緩之</span>。

<span class="c-fire">心</span>主<span class="c-fire">夏</span>，手<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>主治。其日<span class="c-fire">丙丁</span>。<span class="c-fire">心</span>苦<span class="c-fire">緩</span>，急食<span class="c-wood">酸以收之</span>。

<span class="c-earth">脾</span>主<span class="c-earth">長夏</span>，足<span class="c-taiyin">太陰</span><span class="c-yangming">陽明</span>主治。其日<span class="c-earth">戊己</span>。<span class="c-earth">脾</span>苦<span class="c-earth">濕</span>，急食<span class="c-fire">苦以燥之</span>。

<span class="c-metal">肺</span>主<span class="c-metal">秋</span>，手<span class="c-taiyin">太陰</span><span class="c-yangming">陽明</span>主治。其日<span class="c-metal">庚辛</span>。<span class="c-metal">肺</span>苦<span class="c-metal">氣上逆</span>，急食<span class="c-fire">苦以洩之</span>。

<span class="c-water">腎</span>主<span class="c-water">冬</span>，足<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>主治。其日<span class="c-water">壬癸</span>。<span class="c-water">腎</span>苦<span class="c-water">燥</span>，急食<span class="c-metal">辛以潤之，開腠理，致津液通氣</span>也。


<span class="model-tag">[五行－時間／年尺度｜肝病生克轉歸]</span>

病在<span class="c-wood">肝</span>，愈於<span class="c-fire">夏</span>，<span class="c-fire">夏</span>不愈，甚於<span class="c-metal">秋</span>，<span class="c-metal">秋</span>不死，持於<span class="c-water">冬</span>，起於<span class="c-wood">春</span>。禁當<span class="c-wood">風</span>。

<span class="model-tag">[五行－時間／一組天干（十日）為週期｜肝病生克轉歸]</span>

<span class="c-wood">肝</span>病者，愈在<span class="c-fire">丙丁</span>，<span class="c-fire">丙丁</span>不愈，加於<span class="c-metal">庚辛</span>，<span class="c-metal">庚辛</span>不死，持於<span class="c-water">壬癸</span>，起於<span class="c-wood">甲乙</span>。

<span class="model-tag">[五行－時間／日尺度｜肝病日內盛衰]</span>

<span class="c-wood">肝</span>病者，<span class="c-wood">平旦慧</span>，<span class="c-metal">下晡甚</span>，<span class="c-water">夜半靜</span>。

<span class="c-wood">肝</span>欲散，急食<span class="c-metal">辛以散之</span>，用<span class="c-metal">辛補之</span>，<span class="c-wood">酸瀉之</span>。


<span class="model-tag">[五行－時間／年尺度｜心病生克轉歸]</span>

病在<span class="c-fire">心</span>，愈在<span class="c-earth">長夏</span>，<span class="c-earth">長夏</span>不愈，甚於<span class="c-water">冬</span>，<span class="c-water">冬</span>不死，持於<span class="c-wood">春</span>，起於<span class="c-fire">夏</span>。禁<span class="c-warm">溫</span>食<span class="c-hot">熱</span>衣。

<span class="model-tag">[五行－時間／一組天干（十日）為週期｜心病生克轉歸]</span>

<span class="c-fire">心</span>病者，愈在<span class="c-earth">戊己</span>，<span class="c-earth">戊己</span>不愈，加於<span class="c-water">壬癸</span>，<span class="c-water">壬癸</span>不死，持於<span class="c-wood">甲乙</span>，起於<span class="c-fire">丙丁</span>。

<span class="model-tag">[五行－時間／日尺度｜心病日內盛衰]</span>

<span class="c-fire">心</span>病者，<span class="c-fire">日中慧</span>，<span class="c-water">夜半甚</span>，<span class="c-wood">平旦靜</span>。

<span class="c-fire">心</span>欲耎，急食<span class="c-water">咸以耎之</span>；用<span class="c-water">咸補之</span>，<span class="c-earth">甘瀉之</span>。


<span class="model-tag">[五行－時間／年尺度｜脾病生克轉歸]</span>

病在<span class="c-earth">脾</span>，愈在<span class="c-metal">秋</span>，<span class="c-metal">秋</span>不愈；甚於<span class="c-wood">春</span>，<span class="c-wood">春</span>不死，持於<span class="c-fire">夏</span>，起於<span class="c-earth">長夏</span>。禁<span class="c-warm">溫</span>食飽食，<span class="c-earth">濕地濡衣</span>。

<span class="model-tag">[五行－時間／一組天干（十日）為週期｜脾病生克轉歸]</span>

<span class="c-earth">脾</span>病者愈在<span class="c-metal">庚辛</span>，<span class="c-metal">庚辛</span>不愈，加於<span class="c-wood">甲乙</span>，<span class="c-wood">甲乙</span>不死，持於<span class="c-fire">丙丁</span>，起於<span class="c-earth">戊己</span>。

<span class="model-tag">[五行－時間／日尺度｜脾病日內盛衰]</span>

<span class="c-earth">脾</span>病者，<span class="c-earth">日昳慧</span>，<span class="c-wood">日出甚</span>，<span class="c-metal">下晡靜</span>。

<span class="c-earth">脾</span>欲緩，急食<span class="c-earth">甘以緩之</span>，用<span class="c-fire">苦瀉之</span>，<span class="c-earth">甘補之</span>。


<span class="model-tag">[五行－時間／年尺度｜肺病生克轉歸]</span>

病在<span class="c-metal">肺</span>，愈於<span class="c-water">冬</span>。<span class="c-water">冬</span>不愈，甚於<span class="c-fire">夏</span>，<span class="c-fire">夏</span>不死，持於<span class="c-earth">長夏</span>，起於<span class="c-metal">秋</span>。禁<span class="c-cold">寒</span>飲食，<span class="c-cold">寒</span>衣。

<span class="model-tag">[五行－時間／一組天干（十日）為週期｜肺病生克轉歸]</span>

<span class="c-metal">肺</span>病者，愈在<span class="c-water">壬癸</span>，<span class="c-water">壬癸</span>不愈，加於<span class="c-fire">丙丁</span>，<span class="c-fire">丙丁</span>不死，持於<span class="c-earth">戊己</span>，起於<span class="c-metal">庚辛</span>。

<span class="model-tag">[五行－時間／日尺度｜肺病日內盛衰]</span>

<span class="c-metal">肺</span>病者，<span class="c-metal">下晡慧</span>，<span class="c-fire">日中甚</span>，<span class="c-water">夜半靜</span>。

<span class="c-metal">肺</span>欲收，急食<span class="c-wood">酸以收之</span>，用<span class="c-wood">酸補之</span>，<span class="c-metal">辛瀉之</span>。


<span class="model-tag">[五行－時間／年尺度｜腎病生克轉歸]</span>

病在<span class="c-water">腎</span>，愈在<span class="c-wood">春</span>，<span class="c-wood">春</span>不愈，甚於<span class="c-earth">長夏</span>，<span class="c-earth">長夏</span>不死，持於<span class="c-metal">秋</span>，起於<span class="c-water">冬</span>，禁犯焠（火矣）<span class="c-hot">熱</span>食，<span class="c-warm">溫</span>炙衣。

<span class="model-tag">[五行－時間／一組天干（十日）為週期｜腎病生克轉歸]</span>

<span class="c-water">腎</span>病者，愈在<span class="c-wood">甲乙</span>，<span class="c-wood">甲乙</span>不愈，甚於<span class="c-earth">戊己</span>，<span class="c-earth">戊己</span>不死，持於<span class="c-metal">庚辛</span>，起於<span class="c-water">壬癸</span>。

<span class="model-tag">[五行－時間／日尺度｜腎病日內盛衰]</span>

<span class="c-water">腎</span>病者，<span class="c-water">夜半慧</span>，<span class="c-earth">四季甚</span>，<span class="c-metal">下晡靜</span>。

<span class="c-water">腎</span>欲堅，急食<span class="c-fire">苦以堅之</span>，用<span class="c-fire">苦補之</span>，<span class="c-water">咸瀉之</span>。


<span class="model-tag">[五行－時間／年尺度 × 一組天干（十日）為週期｜生克轉歸總則]</span>

夫邪氣之客於身也。以勝相加，至其所生而愈，至其所不勝而甚，至於所生而持，自得其位而起；必先定五臟之脈，乃可言間甚之時，死生之期也。


<span class="model-tag">[五行－空間／人體｜肝 × 足厥陰・少陽]</span>

<span class="c-wood">肝</span>病者，<span class="c-wood">兩脅下痛引少腹，令人善怒</span>。虛則<span class="c-wood">目（盳盳）無所見，耳無所聞，善恐，如人將補之</span>。

取其經<span class="c-jueyin">厥陰</span>與<span class="c-shaoyang">少陽</span>，<span class="c-wood">氣逆則頭痛。耳聾不聰、頰腫</span>、取血者。


<span class="model-tag">[五行－空間／人體｜心 × 手少陰・太陽]</span>

<span class="c-fire">心</span>病者，<span class="c-fire">胸中痛，脅支滿，脅下痛，膺背肩胛間痛，兩臂內痛</span>。虛則<span class="c-fire">胸腹大，脅下與腰相引而痛</span>。

取其經，<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>舌下血者，其變病刺郗中血者。


<span class="model-tag">[五行－空間／人體｜脾 × 足太陰・陽明]</span>

<span class="c-earth">脾</span>病者，<span class="c-earth">身重，善飢肉痿，足不收行，善瘈，腳下痛</span>。虛則<span class="c-earth">腹滿，腸鳴飧洩，食不化</span>。

取其經<span class="c-taiyin">太陰</span>、<span class="c-yangming">陽明</span>、<span class="c-shaoyin">少陰</span>血者。


<span class="model-tag">[五行－空間／人體｜肺 × 手太陰・陽明]</span>

<span class="c-metal">肺</span>病者，<span class="c-metal">喘咳逆氣，肩背痛，汗出，尻陰股膝髀腨胻足皆痛</span>。虛則<span class="c-metal">少氣，不能報息，耳聾嗌乾</span>。

取其經，<span class="c-taiyin">太陰</span>足<span class="c-taiyang">太陽</span>之外，<span class="c-jueyin">厥陰</span>內血者。


<span class="model-tag">[五行－空間／人體｜腎 × 足少陰・太陽]</span>

<span class="c-water">腎</span>病者，<span class="c-water">腹大、脛腫、喘咳身重，寢汗出、憎風</span>。虛則<span class="c-water">胸中痛，大腹、小腹痛，清厥意不樂</span>。

取其經<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>血者。


<span class="model-tag">[五行－空間／人體｜五臟 × 五色 × 五味]</span>

<span class="c-wood">肝色青</span>，宜食<span class="c-earth">甘</span>。<span class="c-earth">粳米、牛肉、棗、葵</span>皆<span class="c-earth">甘</span>。

<span class="c-fire">心色赤</span>，宜食<span class="c-wood">酸</span>。<span class="c-wood">小豆、犬肉、李、韭</span>皆<span class="c-wood">酸</span>。

<span class="c-metal">肺色白</span>，宜食<span class="c-fire">苦</span>。<span class="c-fire">麥、羊肉、杏、薤</span>皆<span class="c-fire">苦</span>。

<span class="c-earth">脾色黃</span>，宜食<span class="c-water">咸</span>。<span class="c-water">大豆、豬肉、栗、藿</span>皆<span class="c-water">咸</span>。

<span class="c-water">腎色黑</span>，宜食<span class="c-metal">辛</span>。<span class="c-metal">黃黍、雞肉、桃、蔥</span>皆<span class="c-metal">辛</span>。

<span class="c-metal">辛散</span>、<span class="c-wood">酸收</span>、<span class="c-earth">甘緩</span>、<span class="c-fire">苦堅</span>、<span class="c-water">咸耎</span>。毒藥攻邪。

五穀為食。五果為助。五畜為益。五菜為充。

氣味合而服之，以補精益氣。

<span class="model-tag">[五行－時間／年尺度 × 五行－空間／人體]</span>

此五者，有<span class="c-metal">辛</span>、<span class="c-wood">酸</span>、<span class="c-earth">甘</span>、<span class="c-fire">苦</span>、<span class="c-water">咸</span>，各有所利，或<span class="c-metal">散</span>，或<span class="c-wood">收</span>、或<span class="c-earth">緩</span>、或<span class="c-wood">急</span>、或<span class="c-fire">堅</span>、或<span class="c-water">耎</span>。四時五臟，病隨五味所宜也。
