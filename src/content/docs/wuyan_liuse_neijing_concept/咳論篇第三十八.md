# 咳論篇第三十八

黃帝問曰：肺之令人咳何也？

岐伯對曰：五臟六腑皆令人咳，非獨肺也。

帝曰：願聞其狀？

岐伯曰：皮毛者肺之合也。皮毛先受邪氣，邪氣以從其合也。其寒飲食入胃，從肺脈上至於肺，則肺寒，肺寒則外內合，邪因而客之，則為肺咳。

五臟各以其時受病，非其時各傳以與之。

人與天地相參，故五臟各以治時，感於寒則受病，微則為咳，甚者為洩為痛。

<span style="display:inline-block;border:1px solid #777;border-radius:4px;padding:2px 7px;font-weight:700;">[五行－時間／年尺度]</span>

乘<span style="color:#B58900;font-weight:600;">秋</span>則<span style="color:#B58900;font-weight:600;">肺</span>先受邪，乘<span style="color:#2E7D32;font-weight:600;">春</span>則<span style="color:#2E7D32;font-weight:600;">肝</span>先受之，乘<span style="color:#C62828;font-weight:600;">夏</span>則<span style="color:#C62828;font-weight:600;">心</span>先受之，乘<span style="color:#8D6E63;font-weight:600;">至陰</span>則<span style="color:#8D6E63;font-weight:600;">脾</span>先受之，乘<span style="color:#1565C0;font-weight:600;">冬</span>則<span style="color:#1565C0;font-weight:600;">腎</span>先受之。

帝曰：何以異之？

<span style="display:inline-block;border:1px solid #777;border-radius:4px;padding:2px 7px;font-weight:700;">[五行－空間／人體]</span>

岐伯曰：<span style="color:#B58900;font-weight:600;">肺</span>咳之狀，<span style="color:#B58900;font-weight:600;">咳而喘息有音</span>，甚則<span style="color:#B58900;font-weight:600;">唾血</span>。

<span style="color:#C62828;font-weight:600;">心</span>咳之狀，咳則<span style="color:#C62828;font-weight:600;">心痛，喉中介介如梗狀</span>，甚則<span style="color:#C62828;font-weight:600;">咽腫，喉痹</span>。

<span style="color:#2E7D32;font-weight:600;">肝</span>咳之狀，咳則<span style="color:#2E7D32;font-weight:600;">兩脅下痛</span>，甚則<span style="color:#2E7D32;font-weight:600;">不可以轉，轉則兩胠下滿</span>。

<span style="color:#8D6E63;font-weight:600;">脾</span>咳之狀，咳則<span style="color:#8D6E63;font-weight:600;">右脅下痛，陰陰引肩背</span>，甚則<span style="color:#8D6E63;font-weight:600;">不可以動，動則咳劇</span>。

<span style="color:#1565C0;font-weight:600;">腎</span>咳之狀，咳則<span style="color:#1565C0;font-weight:600;">腰背相引而痛</span>，甚則<span style="color:#1565C0;font-weight:600;">咳涎</span>。

帝曰：六腑之咳奈何？安所受病？

<span style="display:inline-block;border:1px solid #777;border-radius:4px;padding:2px 7px;font-weight:700;">[陰陽－空間／人體]</span>

岐伯曰：<span style="background:#111;color:#fff;padding:0 3px;border-radius:2px;font-weight:600;">五臟</span>之久咳，乃移於<span style="background:#fff;color:#111;border:1px solid #777;padding:0 3px;border-radius:2px;font-weight:600;">六腑</span>。

<span style="display:inline-block;border:1px solid #777;border-radius:4px;padding:2px 7px;font-weight:700;">[五行－空間／人體]</span>

<span style="color:#8D6E63;font-weight:600;">脾</span>咳不已，則<span style="color:#8D6E63;font-weight:600;">胃</span>受之。<span style="color:#8D6E63;font-weight:600;">胃</span>咳之狀，<span style="color:#8D6E63;font-weight:600;">咳而嘔，嘔甚則長蟲出</span>。

<span style="color:#2E7D32;font-weight:600;">肝</span>咳不已則<span style="color:#2E7D32;font-weight:600;">膽</span>受之，<span style="color:#2E7D32;font-weight:600;">膽</span>咳之狀，<span style="color:#2E7D32;font-weight:600;">咳嘔膽汁</span>。

<span style="color:#B58900;font-weight:600;">肺</span>咳不已則<span style="color:#B58900;font-weight:600;">大腸</span>變之，<span style="color:#B58900;font-weight:600;">大腸</span>咳狀，<span style="color:#B58900;font-weight:600;">咳而遺失</span>。

<span style="color:#C62828;font-weight:600;">心</span>咳不已則<span style="color:#C62828;font-weight:600;">小腸</span>受之，<span style="color:#C62828;font-weight:600;">小腸</span>咳狀，<span style="color:#C62828;font-weight:600;">咳而失氣，氣與咳俱失</span>。

<span style="color:#1565C0;font-weight:600;">腎</span>咳不已則<span style="color:#1565C0;font-weight:600;">膀胱</span>受之，<span style="color:#1565C0;font-weight:600;">膀胱</span>咳狀，<span style="color:#1565C0;font-weight:600;">咳而遺溺</span>。

久咳不已則<span style="color:#B71C1C;font-weight:600;">三焦</span>受之，<span style="color:#B71C1C;font-weight:600;">三焦</span>咳狀，<span style="color:#B71C1C;font-weight:600;">咳而腹滿不欲食飲</span>。

此皆緊於胃關於肺，使人多涕唾而面浮腫氣逆也。

帝曰：治之奈何？

岐伯曰：治臟者治其俞，治腑者治其合，浮腫者治其經。

帝曰：善。
