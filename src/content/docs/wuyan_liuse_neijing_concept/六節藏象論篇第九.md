<span class="model-tag">[九九八十一宮]</span>

黃帝問焉：余聞以六六之節，以成一歲，人以九九制會，計人亦有三百六十五節，以為天地，久矣。不知其所謂也？

岐伯對曰：昭乎哉問也，請遂言之！夫六六之節，九九制會者，所以正天之度，氣之數也。天度者，所以制日月之行也，氣數者，所以紀化生之用也。


<span class="model-tag">[陰陽－空間／天地]</span>

<span class="c-yang">天</span>為<span class="c-yang">陽</span>，<span class="c-yin">地</span>為<span class="c-yin">陰</span>；<span class="c-yang">日</span>為<span class="c-yang">陽</span>，<span class="c-yin">月</span>為<span class="c-yin">陰</span>；行有分紀，周有道理。<span class="c-yang">日</span>行一度，<span class="c-yin">月</span>行十三度而有奇焉。故大小月三百六十五日而成歲，積氣余而盈閏矣。

立端於始，表正於中，推余於終，而天度畢矣。

帝曰：余已聞天度矣。願聞氣數，何以合之？


<span class="model-tag">[陰陽－空間／天地]</span>
<span class="model-tag">[五行－時間／一組天干（十日）為週期]</span>
<span class="model-tag">[六十甲子]</span>
<span class="model-tag">[九九八十一宮]</span>

岐伯曰：<span class="c-yang">天</span>以六六為節，<span class="c-yin">地</span>以九九制會，天有十日，日六竟而周甲，甲六覆而終歲，三百六十日法也。


<span class="model-tag">[陰陽－空間／天地]</span>

夫自古通天者，生之本，本於<span class="c-yin">陰</span><span class="c-yang">陽</span>。

<span class="model-tag">[九宮（八風）－空間]</span>
<span class="model-map">其氣九州九竅，皆通乎<span class="c-yang">天氣</span>。</span>

故其生五，其氣三。

<span class="model-tag">[九宮（八風）－空間]</span>
<span class="model-map">三而成<span class="c-yang">天</span>，三而成<span class="c-yin">地</span>，三而成人，三而三之，合則為九。九分為九野，九野為九臟；故形臟四，神臟五，合為九臟以應之也。</span>

帝曰：余已聞六六九九之會也，夫子言積氣盈闊，願聞何謂氣？請夫子發蒙解惑焉。

岐伯曰：此上帝所秘，先師傳之也。

帝曰：請遂聞之。


岐伯曰：

<span class="model-tag">[二十四節氣－年尺度]</span>
<span class="model-map">五日謂之候，三候謂之氣，六氣謂之時，四時謂之歲</span>，而各從其主治焉。

<span class="model-tag">[五行－時間／年尺度]</span>
<span class="model-map">五運相襲而皆治之，終期之日，周而復始，時立氣布，如環無端，候亦同法。</span>

故曰不知年之所加，氣之盛衰，虛實之所起，不可以為工矣。

帝曰：五運之始，如環無端，其太過不及如何？

岐伯曰：五氣更立，各有所勝，盛虛之變，此其常也。

帝曰：平氣何如？岐伯曰，無過者也。

帝曰：太過不及奈何？

岐伯曰：在經有也。

帝曰：何謂所勝？


<span class="model-tag">[五行－時間／年尺度｜五行時之勝]</span>

岐伯曰：<span class="c-wood">春</span>勝<span class="c-earth">長夏</span>，<span class="c-earth">長夏</span>勝<span class="c-water">冬</span>，<span class="c-water">冬</span>勝<span class="c-fire">夏</span>，<span class="c-fire">夏</span>勝<span class="c-metal">秋</span>，<span class="c-metal">秋</span>勝<span class="c-wood">春</span>，所謂得五行時之勝，各以氣命其臟。

帝曰：何以知其勝？

岐伯曰：求其至也，皆歸始<span class="c-wood">春</span>，未至而至，此謂太過，則薄所不勝，而乘所勝也。命曰氣淫不分，邪僻內生，工不能禁。至而不至，此謂不及，則所勝妄行，而所生受病，所不勝薄之也，命曰氣迫。所謂求其至者，氣至之時也。謹候其時，氣可與期，失時反候，五治不分，邪僻內生，工不能禁也。

帝曰：有不襲乎？

岐伯曰：蒼天之氣，不得無常也。氣之不襲是謂非常，非常則變矣。

帝曰：非常而變奈何？

岐伯曰：變至則病，所勝則微，所不勝則甚。因而重感於邪則死矣，故非其時則微，當其時則甚也。

帝曰：善。余聞氣合而有形，因變以正名。<span class="c-yang">天</span><span class="c-yin">地</span>之運，<span class="c-yin">陰</span><span class="c-yang">陽</span>之化，其於萬物孰少孰多，可得聞乎？


岐伯曰：悉哉問也，<span class="c-yang">天</span>至廣，不可度，<span class="c-yin">地</span>至大，不可量。大神靈問，請陳其方。草生五色，五色之變，不可勝視，草生五味，五味之美不可勝極，嗜慾不同，各有所通。

<span class="model-tag">[陰陽－空間／天地]</span>
<span class="model-map"><span class="c-yang">天</span>食人以<span class="c-yang">五氣</span>，<span class="c-yin">地</span>食人以<span class="c-yin">五味</span>。</span>

<span class="model-tag">[陰陽－空間／人體]</span>
<span class="model-map"><span class="c-yang">五氣</span>入鼻，藏於<span class="c-yang">心肺</span>，上使五色修明，音聲能彰；<span class="c-yin">五味</span>入口，藏於<span class="c-yin">腸胃</span>，味有所藏，以養<span class="c-yang">五氣</span>，氣和而生，津液相成，神乃自生。</span>

帝曰：臟象何如？

岐伯曰：


<span class="model-tag">[五行－空間／人體｜五臟藏象]</span>
<span class="model-tag">[陰陽－空間／人體]</span>
<span class="model-tag">[五行－時間／年尺度]</span>

<span class="c-fire">心</span>者，<span class="c-fire">生之本，神之變</span>也；其華在<span class="c-fire">面</span>，其充在<span class="c-fire">血脈</span>，為<span class="c-yang">陽</span>中之<span class="c-taiyang">太陽</span>，通於<span class="c-fire">夏氣</span>。

<span class="c-metal">肺</span>者，<span class="c-metal">氣之本，魄之處</span>也；其華在<span class="c-metal">毛</span>，其充在<span class="c-metal">皮</span>，為<span class="c-yang">陽</span>中之<span class="c-taiyin">太陰</span>，通於<span class="c-metal">秋氣</span>。

<span class="c-water">腎</span>者，<span class="c-water">主蟄，封藏之本，精之處</span>也；其華在<span class="c-water">發</span>，其充在<span class="c-water">骨</span>，為<span class="c-yin">陰</span>中之<span class="c-shaoyin">少陰</span>，通於<span class="c-water">冬氣</span>。

<span class="c-wood">肝</span>者，<span class="c-wood">罷極之本，魂之居</span>也；其華在<span class="c-wood">爪</span>，其充在<span class="c-wood">筋</span>，以<span class="c-wood">生血氣</span>，其味<span class="c-wood">酸</span>，其色<span class="c-wood">蒼</span>，此為<span class="c-yang">陽</span>中之<span class="c-shaoyang">少陽</span>，通於<span class="c-wood">春氣</span>。

<span class="c-earth">脾、胃、大腸、小腸、三焦、膀胱</span>者，<span class="c-earth">倉廩之本，營之居</span>也，名曰<span class="c-earth">器</span>，能<span class="c-earth">化糟粕，轉味而入出</span>者也，其華在<span class="c-earth">唇四白</span>，其充在<span class="c-earth">肌</span>，其味<span class="c-earth">甘</span>，其色<span class="c-earth">黃</span>，此<span class="c-yin">至陰</span>之類，通於<span class="c-earth">土氣</span>。

凡十一臟，取決於膽也。


<span class="model-tag">[三陰三陽－空間／人體｜人迎・寸口]</span>

故人迎一盛病在<span class="c-shaoyang">少陽</span>、二盛病在<span class="c-taiyang">太陽</span>、三盛病在<span class="c-yangming">陽明</span>、四盛已上為<span class="c-yang">格陽</span>。

寸口一盛病在<span class="c-jueyin">厥陰</span>、二盛病在<span class="c-shaoyin">少陰</span>、三盛病在<span class="c-taiyin">太陰</span>、四盛已上為<span class="c-yin">關陰</span>。


<span class="model-tag">[陰陽－空間／天地]</span>

人迎與寸口俱盛四倍以上為關格。關格之脈，贏不能極於<span class="c-yang">天</span><span class="c-yin">地</span>之精氣，則死矣。
