黃帝問曰：余聞方士，或以腦髓為臟，或以腸胃為臟，或以為腑。敢問更相反，皆自謂是，不知其道，願聞其說。  
<span class="model-tag">[陰陽－空間／人體｜奇恆之府・傳化之府]</span>
<div class="model-map">岐伯對曰：<span class="c-yin">腦、髓、骨、脈、膽、女子胞</span>，此六者，<span class="c-yin">地氣</span>之所生也。皆臟於<span class="c-yin">陰</span>而象於<span class="c-yin">地</span>，故<span class="c-yin">藏而不瀉</span>，名曰奇恆之府。</div>
<div class="model-map">夫<span class="c-yang">胃、大腸、小腸、三焦、膀胱</span>，此五者<span class="c-yang">天氣</span>之所生也，其氣象<span class="c-yang">天</span>，故<span class="c-yang">瀉而不藏</span>。此受五藏濁氣，名曰傳化之府，此不能久留，輸瀉者也。</div>
魄門亦為五臟使，水谷不得久藏。  

<span class="model-tag">[陰陽－空間／人體｜五臟藏・六腑瀉]</span>
<div class="model-map">所謂<span class="c-yin">五臟者</span>，<span class="c-yin">藏精氣而不瀉</span>也，故<span class="c-yin">滿而不能實</span>。</div>
<div class="model-map"><span class="c-yang">六腑者</span>，<span class="c-yang">傳化物而不藏</span>，故<span class="c-yang">實而不能滿</span>也。所以然者，水谷入口則胃實而腸虛，食下則腸實而胃虛。</div>
故曰實而不滿，滿而不實也。  
帝曰：氣口何以獨為五臟之主？  

<span class="model-tag">[三陰三陽－空間／人體｜氣口太陰]</span>
<span class="model-tag">[五行－空間／人體]</span>
<div class="model-map">岐伯曰：胃者水谷之海，六腑之大源也。<span class="c-yin">五味</span>入口，藏於胃以養五臟氣，氣口亦<span class="c-taiyin">太陰</span>也，是以五臟六腑之氣味，皆出於胃，變見於氣口。故<span class="c-yang">五氣</span>入鼻，藏於<span class="c-yang">心肺</span>，<span class="c-yang">心肺</span>有病，而<span class="c-yang">鼻為之不利</span>也。</div>
凡治病必察其下，適其脈，觀其志意，與其病也。  
拘於鬼神者，不可與言至德；惡於針石者，不可與言至巧。病不許治者，病必不治，治之無功矣。
