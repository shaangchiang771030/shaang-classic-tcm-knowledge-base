# Cosmos Order

Cosmos Order is a research-led knowledge platform for reconstructing the systems logic of classical medicine. The full English article library is being prepared; the site structure and language routing are already in place.

> Chinese filenames may be retained for translated Markdown files so that maintainers can identify paired articles easily. Translation identity is managed by `translationKey`, not by forcing English filenames.
