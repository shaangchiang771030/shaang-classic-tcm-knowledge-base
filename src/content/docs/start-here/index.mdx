# 開始閱讀

Cosmos Order 不要求所有讀者從同一篇開始。內容分成 **基礎、進階、研究** 三個深度；「基礎」並不等於科普，而是建立後續推導所需要的第一層模型。

## 內容深度

- **基礎**：建立該領域不可缺少的模型。
- **進階**：需要前置模型，開始組合多個結構與推導。
- **研究**：進入原典重建、反例、模型比較、驗證或尚未完全封閉的問題。
