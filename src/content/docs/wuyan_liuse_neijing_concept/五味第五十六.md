<span class="model-tag">[五行－空間／人體｜五味入五臟]</span>
<div class="model-map">黃帝曰：願聞谷氣有五味，其入五臟，分別奈何？伯高曰：<span class="c-earth">胃</span>者，五臟六腑之海也，水谷皆入於胃，五臟六腑，皆稟氣於胃。五味各走其所喜，谷味<span class="c-wood">酸，先走肝</span>，谷味<span class="c-fire">苦，先走心</span>，谷味<span class="c-earth">甘，先走脾</span>，谷味<span class="c-metal">辛，先走肺</span>，谷味<span class="c-water">咸，先走腎</span>。谷氣津液已行，營衛大通，乃化糟粕，以次傳下。</div>

<span class="model-tag">[陰陽－空間／人體｜營衛・出入]</span>
<div class="model-map">黃帝曰：<span class="c-yin">營</span><span class="c-yang">衛</span>之行奈何？伯高曰：谷始入於胃，其精微者，先出於胃之兩焦，以溉五臟，別出兩行，<span class="c-yin">營</span><span class="c-yang">衛</span>之道。其大氣之搏而不行者，積於胸中，命曰氣海，出於肺，循咽喉，故呼則<span class="c-yang">出</span>，吸則<span class="c-yin">入</span>。天地之精氣，其大數常出三入一，故谷不入，半日則氣衰，一日則氣少矣。</div>

<span class="model-tag">[五行－五味｜五穀・五果・五畜・五菜]</span>
<div class="model-map">黃帝曰：谷之五味，可得聞乎？伯高曰：請盡言之。五穀：<span class="c-earth">糠米甘</span>，<span class="c-wood">麻酸</span>，<span class="c-water">大豆咸</span>，<span class="c-fire">麥苦</span>，<span class="c-metal">黃黍辛</span>。五果：<span class="c-earth">棗甘</span>，<span class="c-wood">李酸</span>，<span class="c-water">栗咸</span>，<span class="c-fire">杏苦</span>，<span class="c-metal">桃辛</span>。五畜：<span class="c-earth">牛甘</span>，<span class="c-wood">犬酸</span>，<span class="c-water">豬咸</span>，<span class="c-fire">羊苦</span>，<span class="c-metal">雞辛</span>。五菜：<span class="c-earth">葵甘</span>，<span class="c-wood">韭酸</span>，<span class="c-water">藿咸</span>，<span class="c-fire">薤苦</span>，<span class="c-metal">蔥辛</span>。</div>

<span class="model-tag">[五行－空間／人體｜五色・五宜]</span>
<div class="model-map">五色：<span class="c-earth">黃色宜甘</span>，<span class="c-wood">青色宜酸</span>，<span class="c-water">黑色宜咸</span>，<span class="c-fire">赤色宜苦</span>，<span class="c-metal">白色宜辛</span>。凡此五者，各有所宜。五宜所言五色者，<span class="c-earth">脾病者</span>，宜食<span class="c-earth">糠米飯，牛肉棗葵</span>；<span class="c-fire">心病者</span>，宜食<span class="c-fire">麥羊肉杏薤</span>；<span class="c-water">腎病者</span>，宜食<span class="c-water">大豆黃卷豬肉栗藿</span>；<span class="c-wood">肝病者</span>，宜食<span class="c-wood">麻犬肉李韭</span>；<span class="c-metal">肺病者</span>，宜食<span class="c-metal">黃黍雞肉桃蔥</span>。</div>

<span class="model-tag">[五行－空間／人體｜五禁]</span>
<div class="model-map">五禁：<span class="c-wood">肝病</span>禁<span class="c-metal">辛</span>，<span class="c-fire">心病</span>禁<span class="c-water">咸</span>，<span class="c-earth">脾病</span>禁<span class="c-wood">酸</span>，<span class="c-water">腎病</span>禁<span class="c-earth">甘</span>，<span class="c-metal">肺病</span>禁<span class="c-fire">苦</span>。</div>

<span class="model-tag">[五行－空間／人體｜臟色與調味]</span>
<div class="model-map"><span class="c-wood">肝色青</span>，<span class="c-earth">宜食甘</span>，<span class="c-earth">糠米飯、牛肉、棗、葵皆甘</span>。<span class="c-fire">心色赤</span>，<span class="c-wood">宜食酸</span>，<span class="c-wood">犬肉、麻、李、韭皆酸</span>。<span class="c-earth">脾黃色</span>，<span class="c-water">宜食咸</span>，<span class="c-water">大豆、豬肉、栗、藿皆咸</span>。<span class="c-metal">肺白色</span>，<span class="c-fire">宜食苦</span>，<span class="c-fire">麥、羊肉、杏、薤皆苦</span>。<span class="c-water">腎色黑</span>，<span class="c-metal">宜食辛</span>，<span class="c-metal">黃黍、雞肉、桃、蔥皆辛</span>。</div>
