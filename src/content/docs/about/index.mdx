# Cosmos Order

Cosmos Order 是一個**古典醫學理論整合平台**。我們希望以具有千古歷史的經典為主，整理散落在知識、診法、經絡、藥物、經方與五運六氣中的規則。

利用**以經解經**的精神，做為老祖宗智慧的忠實翻譯者，以便在這個因科技發展而動盪不安的年代，給予群眾們安身立命之本。

我們希望利用簡潔文字，保留老祖宗的用語，但又貼近現代人相對能接受的形式，為古中醫正本清源，還給老祖宗們當年的苦心一個公道。

## 創建者

## 為什麼開始

作者本人在 2017／2018 年短暫的創業項目——十四萬條名老中醫資料所訓練的大數據型中醫大腦——結束後，才發現到一件事。

現代中醫療效不彰，是因為這百年來，對古中醫的誤解，在「師心自用」的情況下，不知不覺中切斷了與幾千年前中醫本質的臍帶。

但另一方面，與自己的中醫顧問，又見證了在古中醫理論上衍生的臨床療效。

因此，這九年來，作者的工作是搜集和尋找《內經》《難經》《甲乙經》、桂林古本等經典背後的本質模型，以便還給千年前老祖宗及其智慧一個公道和真相。

藉此，也感謝幾位堅守於古中醫的老師們的無私教誨：潘曉川教授、樊佳如先生（筆名：假如明天來臨）、文碩老師、路輝老師。
