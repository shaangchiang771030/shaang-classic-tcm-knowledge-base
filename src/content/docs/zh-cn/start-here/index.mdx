# 开始阅读

Cosmos Order 不要求所有读者从同一篇开始。内容分成 **基础、进阶、研究** 三个深度；“基础”并不等于科普，而是建立后续推导所需要的第一层模型。

  <a class="cosmos-card" href="/zh-cn/research/spacetime/"><strong>天地模型</strong><span>适合想理解阴阳、五行、三阴三阳与时空模型的读者。</span></a>
  <a class="cosmos-card" href="/zh-cn/research/qihua-physiology/"><strong>人体模型</strong><span>适合想理解脏腑、经络、六经与营卫如何接成一个动态系统的读者。</span></a>
  <a class="cosmos-card" href="/zh-cn/research/jingfang/"><strong>治疗模型</strong><span>适合想理解五味、治法、经方与药物如何从条件中生成的读者。</span></a>
</div>

## 内容深度

- **基础**：建立该领域不可缺少的模型。
- **进阶**：需要前置模型，开始组合多个结构与推导。
- **研究**：进入原典重建、反例、模型比较、验证或尚未完全封闭的问题。
