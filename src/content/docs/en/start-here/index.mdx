# Start Here

Cosmos Order does not require every reader to begin with the same article. Content is organized by depth—**Foundation, Advanced, and Research**. “Foundation” does not mean simplified popularization; it means the first model required for later reasoning.

## Content Depth

- **Foundation**: establishes indispensable models for the domain.
- **Advanced**: combines multiple structures and requires prior models.
- **Research**: enters textual reconstruction, counterexamples, model comparison, validation, or questions that are not yet fully closed.
