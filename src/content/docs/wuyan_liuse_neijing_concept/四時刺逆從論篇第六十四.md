<div class="model-map">
<span class="c-jueyin">厥陰</span>有餘病<span class="c-yin">陰痹</span>；不足病生<span class="c-hot">熱痹</span>；滑則病<span class="c-wood">狐疝風</span>；澀則病<span class="c-jueyin">少腹積氣</span>。  
<span class="c-shaoyin">少陰</span>有餘<span class="c-metal">皮痹隱軫</span>；不足病<span class="c-metal">肺痹</span>；滑則病<span class="c-metal">肺風疝</span>；澀則病<span class="c-shaoyin">積溲血</span>。  
<span class="c-taiyin">太陰</span>有餘，病<span class="c-earth">肉痹</span>，<span class="c-cold">寒中</span>；不足病<span class="c-earth">脾痹</span>；滑則病<span class="c-earth">脾風疝</span>；澀則病<span class="c-taiyin">積，心腹時滿</span>。  
<span class="c-yangming">陽明</span>有餘，病<span class="c-fire">脈痹身時熱</span>；不足病<span class="c-fire">心痹</span>；滑則病<span class="c-fire">心風疝</span>；澀則病<span class="c-yangming">積，時善驚</span>。  
<span class="c-taiyang">太陽</span>有餘病<span class="c-water">骨痹，身重</span>；不足病<span class="c-water">腎痹</span>；滑則病<span class="c-water">腎風疝</span>；澀則病<span class="c-taiyang">積，善時巔疾</span>。  
<span class="c-shaoyang">少陽</span>有餘病<span class="c-wood">筋痹、脅滿</span>；不足病<span class="c-wood">肝痹</span>，滑則病<span class="c-wood">肝風疝</span>；澀則病<span class="c-wood">積，時筋急目痛</span>。  
</div>

<span class="model-tag">[五行－時間／年尺度｜四時氣位]</span>
<span class="model-tag">[五行－空間／人體｜四時氣血層位]</span>

<div class="model-map">
是故<span class="c-wood">春</span>氣在<span class="c-wood">經脈</span>，<span class="c-fire">夏</span>氣在<span class="c-fire">孫絡</span>；<span class="c-earth">長夏</span>氣在<span class="c-earth">肌肉</span>，<span class="c-metal">秋</span>氣在<span class="c-metal">皮膚</span>，<span class="c-water">冬</span>氣在<span class="c-water">骨髓</span>中。  
</div>

帝曰：余願聞其故。  

<div class="model-map">
岐伯曰：<span class="c-wood">春</span>者天氣始開，地氣始洩，凍解冰釋，水行經通，故人氣在<span class="c-wood">脈</span>。<span class="c-fire">夏</span>者經滿氣溢，入<span class="c-fire">孫絡</span>受血，皮膚充實。<span class="c-earth">長夏</span>者，經絡皆盛，內溢<span class="c-earth">肌</span>中。<span class="c-metal">秋</span>者天氣始收，<span class="c-metal">腠理</span>閉塞，<span class="c-metal">皮膚</span>引急。<span class="c-water">冬</span>者，蓋藏血氣在中。內著<span class="c-water">骨髓</span>，通於五臟。是故邪氣者，常隨四時之氣血而入客也。至其變化，不可為度，然必從其經氣，辟除其邪，除其邪則亂氣不生。  
</div>

帝曰：逆四時而生亂氣奈何？  

<span class="model-tag">[五行－時間／年尺度｜四時]</span>
<span class="model-tag">[五行－空間／人體｜逆刺層位]</span>
<span class="model-tag">[陰陽－空間／人體｜內外・上下]</span>

<div class="model-map">
岐伯曰：<span class="c-wood">春</span>刺<span class="c-fire">絡脈</span>，血氣<span class="c-yang">外溢</span>，令人少氣；<span class="c-wood">春</span>刺<span class="c-earth">肌肉</span>，血氣環逆，令人<span class="c-yang">上</span>氣；<span class="c-wood">春</span>刺<span class="c-wood">筋</span><span class="c-water">骨</span>，血氣<span class="c-yin">內著</span>，令人腹脹。  
<span class="c-fire">夏</span>刺<span class="c-wood">經脈</span>，血氣乃竭，令人解（亻亦）；<span class="c-fire">夏</span>刺<span class="c-earth">肌肉</span>，血氣<span class="c-yin">內卻</span>，令人善恐；<span class="c-fire">夏</span>刺<span class="c-wood">筋</span><span class="c-water">骨</span>，血氣<span class="c-yang">上逆</span>，令人善怒。  
<span class="c-metal">秋</span>刺<span class="c-wood">經脈</span>，血氣<span class="c-yang">上逆</span>，令人善忘，<span class="c-metal">秋</span>刺<span class="c-fire">絡脈</span>，氣不<span class="c-yang">外</span>行，令人臥，不欲動；<span class="c-metal">秋</span>刺<span class="c-wood">筋</span><span class="c-water">骨</span>，血氣<span class="c-yin">內散</span>，令人寒栗。  
<span class="c-water">冬</span>刺<span class="c-wood">經脈</span>，氣血皆脫，令人目不明；<span class="c-water">冬</span>刺<span class="c-fire">絡脈</span>，<span class="c-yin">內</span>氣<span class="c-yang">外洩</span>，留為大痹，<span class="c-water">冬</span>刺<span class="c-earth">肌肉</span>，<span class="c-yang">陽氣竭絕</span>，令人善忘。  
</div>

凡此四時刺者，大逆之病，不可不從也，反之則生亂氣相淫病焉。故刺不知四時之經，病之所生，以從為逆，正氣內亂，與精相薄，必審九候，正氣不亂，精氣不轉。  

帝曰：善。  

<span class="model-tag">[五行－空間／人體｜五臟刺傷所變]</span>

<div class="model-map">
刺五臟中<span class="c-fire">心</span>一曰死，其動為<span class="c-fire">噫</span>。中<span class="c-wood">肝</span>五日死，其動為<span class="c-wood">語</span>。中<span class="c-metal">肺</span>三日死，其動為<span class="c-metal">咳</span>。中<span class="c-water">腎</span>六日死，其動為<span class="c-water">嚏欠</span>。中<span class="c-earth">脾</span>十日死，其動為<span class="c-earth">吞</span>。刺傷人五臟必死，其動則依其藏之所變候，知其死也。  
</div>
