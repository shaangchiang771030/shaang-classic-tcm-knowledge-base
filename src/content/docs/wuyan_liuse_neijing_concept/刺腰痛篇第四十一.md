<span class="model-tag">[三陰三陽－空間／人體｜六經腰痛]</span>
<span class="model-tag">[四象－時間／年尺度｜四時刺禁]</span>

<div class="model-map"><span class="c-taiyang">足太陽脈</span>令人<span class="c-taiyang">腰痛，引項脊尻背如重狀</span>，刺其郄中。<span class="c-taiyang">太陽正經</span>出血，<span class="c-yinyang">春</span>無見血。</div>
<div class="model-map"><span class="c-shaoyang">少陽</span>令人<span class="c-shaoyang">腰痛，如以針刺其皮中，循循然不可以俯仰，不可以顧</span>。刺<span class="c-shaoyang">少陽</span>成骨之端出血，成骨在膝外廉之骨獨起者，<span class="c-yangyang">夏</span>無出血。</div>
<div class="model-map"><span class="c-yangming">陽明</span>令人<span class="c-yangming">腰痛，不可以顧，顧如有見者，善悲</span>。刺<span class="c-yangming">陽明</span>於（骨行）前三痏，上下和之出血，<span class="c-yangyin">秋</span>無見血。</div>
<div class="model-map"><span class="c-shaoyin">足少陰</span>令人<span class="c-shaoyin">腰痛，痛引脊內廉</span>。刺<span class="c-shaoyin">少陰</span>於內踝上二痏。<span class="c-yinyang">春</span>無見血，出血太多，不可復也。</div>
<div class="model-map"><span class="c-jueyin">厥陰之脈</span>令人<span class="c-jueyin">腰痛，腰中如張弓弩弦</span>。刺<span class="c-jueyin">厥陰之脈</span>，在腨踵魚腹之外，循之累累然，乃刺之。其病令人<span class="c-jueyin">善言默默然不慧</span>，刺之三痏。</div>

<span class="model-tag">[三陰三陽－空間／人體｜別脈／奇脈會經路由]</span>

<span class="c-taiyang">解脈</span>令人<span class="c-taiyang">腰痛，痛引肩，目（盳盳）然，時遺溲</span>。刺<span class="c-taiyang">解脈</span>，在膝筋肉分間郄外廉之橫脈出血，血變而止。  
<span class="c-taiyang">解脈</span>令人<span class="c-taiyang">腰痛如引帶，常如折腰狀，善恐</span>。刺<span class="c-taiyang">解脈</span>，在郄中結絡如黍米，刺之血射，以黑見赤血而已。  
<span class="c-shaoyang">同陰之脈</span>令人<span class="c-shaoyang">腰痛，痛如小錘居其中，怫然腫</span>。刺<span class="c-shaoyang">同陰之脈</span>在外踝上絕骨之端，為三痏。  
<span class="c-taiyang">陽維之脈</span>令人<span class="c-taiyang">腰痛，痛上怫然腫</span>。刺<span class="c-taiyang">陽維之脈</span>，脈與<span class="c-taiyang">太陽</span>合端下間，去地一尺所。  
<span class="c-taiyang">衡絡之脈</span>令人<span class="c-taiyang">腰痛，不可以俛仰，仰則恐僕，得之舉重傷腰，衡絡絕，惡血歸之</span>。刺之在郄陽、筋之間，上郄數寸，衡居為二痏出血。  
<span class="c-taiyang">會陰之脈</span>令人<span class="c-taiyang">腰痛，痛上漯漯然汗出。汗乾令人欲飲，飲已欲走</span>。刺直腸之脈上三痏，在蹻上郄下五寸橫居，視其盛者出血。  
<span class="c-shaoyin">飛陽之脈</span>令人<span class="c-shaoyin">腰痛，痛上怫怫然，甚則悲以恐</span>。刺<span class="c-shaoyin">飛陽之脈</span>，在內踝上五寸，<span class="c-shaoyin">少陰</span>之前，與陰維之會。  
<span class="c-shaoyin">昌陽之脈</span>令人<span class="c-shaoyin">腰痛，痛引膺，目（盳盳）然，甚則反折，舌卷不能言</span>。刺內筋為二痏。在內踝上大筋前<span class="c-taiyin">太陰</span>後，上踝二寸所。  
<span class="c-taiyin">散脈</span>令人<span class="c-taiyin">腰痛而熱，熱甚生煩，腰下如有橫木居其中，甚則遺溲</span>。刺<span class="c-taiyin">散脈</span>在膝前骨肉分間，絡外廉，束脈為三痏。  
<span class="c-shaoyang">肉里之脈</span>令人<span class="c-shaoyang">腰痛，不可以咳，咳則筋縮急</span>。刺<span class="c-shaoyang">肉里之脈</span>，為二痏，在<span class="c-taiyang">太陽</span>之外，<span class="c-shaoyang">少陽</span>絕骨之後。  

<span class="model-tag">[三陰三陽－空間／人體｜刺法路由]</span>

<div class="model-map"><span class="c-taiyang">腰痛挾脊而痛至頭，幾幾然，目（盳盳）然僵僕</span>，刺<span class="c-taiyang">足太陽</span>郄中出血。</div>
<div class="model-map"><span class="c-taiyang">腰痛上寒</span>，刺<span class="c-taiyang">足太陽</span><span class="c-yangming">陽明</span>；<span class="c-jueyin">上熱</span>刺<span class="c-jueyin">足厥陰</span>；<span class="c-shaoyang">不可以俛仰</span>，刺<span class="c-shaoyang">足少陽</span>；<span class="c-shaoyin">中熱而喘</span>，刺足中出血。（少陰，刺</div>
<div class="model-map"><span class="c-yangming">腰痛上寒不可顧</span>，刺<span class="c-yangming">足陽明</span>；<span class="c-taiyin">上熱</span>刺<span class="c-taiyin">足太陰</span>；<span class="c-shaoyin">中熱而喘</span>，刺<span class="c-shaoyin">足少陰</span>。</div>
<div class="model-map"><span class="c-shaoyin">大便難</span>，刺<span class="c-shaoyin">足少陰</span>；<span class="c-jueyin">少腹滿</span>，刺<span class="c-jueyin">足厥陰</span>。<span class="c-taiyang">如折不可以俛仰，不可舉</span>，刺<span class="c-taiyang">足太陽</span>；<span class="c-shaoyin">引脊內廉</span>，刺<span class="c-shaoyin">足少陰</span>。</div>
<div class="model-map">腰痛引少腹控眇，不可以仰；刺腰尻交者，兩髁胛上，<span class="model-tag">[四象－月亮／月尺度]</span>以月生死為痏數，發針立已，左取右，右取左。</div>
