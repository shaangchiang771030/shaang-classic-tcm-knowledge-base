七つの運気場が同時に作用するとき、とくに注目すべき構造があります。それが `4+3` です。

これは七つの場が分散せず、二つの強い五行クラスターにすべて集まることを意味します。たとえば四つの場が火、三つが木であったり、四つが金、三つが火であったりします。

「強さ」だけで見れば、どちらも 4+3 です。しかし『内経』の五行理論は、**木と火は相生であり、火と金は相剋である。同じ強度でも同じ病機ではない**ことを思い出させます。

約四万件の医案に含まれる実際の暦構造も、この点を示しました。282 件の 4+3 症例は無作為に並んでいたわけではなく、約 **248 件が火4＋木3**、約 **32 件が金4＋火3** でした。つまり、実際の五運六気暦そのものが、出現し得る状態空間をかなり狭く制約していたことになります。

「木3生火4」の症例では、咳、喘、浮腫、嘔吐、煩熱などの症状がまとまって現れやすく、木と火が互いに助長しながら病機の範囲を同時に開く状態に似ています。これは中医学でよくいう「風火相煽」に近いものです。孤立した風証が先にあり、そこへ火証を追加するのではなく、二つの気化モードが互いを増幅していると見ることができます。

さらに注目すべきなのが「火3剋金4」です。

病機が静的な五行関係だけで止まるなら、主として火と金の問題が見えるはずです。しかし実際の Clinical Path はそこで止まらず、多くが**水と木**へ流れていました。最も強い一群では、分類可能な病機のおよそ九割がこの二つの下流方向に落ちていました。

ここから、「カスケード」に似た現象が見え始めます。ある五行衝突が起きた後、病機は最初に作用を受けた臓腑だけに止まるとは限らず、生剋ネットワークに沿って次の地点へ移る可能性があります。

ただし、ここでは節度が必要です。現時点で言えるのは、「火剋金の場の後に、水・木の病機ルートがより多く現れた」ということまでです。「まず肺金が必ず損なわれ、次に腎水が枯れ、さらに肝木が養われなくなる」と直接翻訳することはまだできません。医案の病機 Path は、各地点が虚・実・損傷・代償のどれなのかをまだ完全には区別していないからです。

それでも、これは 4+3 の読み方を変えます。

今後 `4+3` を見たとき、「共振七級」とだけ記すのでは不十分です。少なくとも次を問う必要があります。

**どの二行なのか。どちらが主クラスターで、どちらが副クラスターなのか。相生か相剋か。病機は最終的にどの地点で止まるのか。**

これは『内経』が繰り返し述べる「亢害承制」「子母相及」「勝復」と響き合います。運気は五つの静的な箱ではなく、伝達・転向・補償が起こり得る病機ネットワークに近いものです。

このように理解してこそ、五運六気は暦法の知識から臨床辨証へと本当の意味で戻ってきます。
