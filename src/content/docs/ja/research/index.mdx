# 研究領域

COSMOS ORDER は、古典医学をばらばらな術語や経験則の集積としてではなく、相互に接続できるモデル・規則・観測・治療文法として再構成することを目指しています。

初めて読む方は、各領域の「認知曲線」と領域ガイドから入ると、記事番号や旧来の分類に縛られず、現在の推奨読書順に沿って進めます。

## 六つの研究領域

### [時空](/ja/research/spacetime/)
陰陽・四象・五行・三陰三陽を、時間尺度と空間尺度を区別しながらモデル言語として読み直します。

### [気化生理](/ja/research/qihua-physiology/)
一気、升降出入、中土、臓腑、経絡、六経、営衛から、正常な人体の動的モデルを組み立てます。

### [経方](/ja/research/jingfang/)
五味、時空二重座標、六気場面、治法文法を通じて、「なぜこの処方なのか」という生成規則を追います。

### [薬物](/ja/research/materia-medica/)
薬物を効能タグの集合ではなく、多次元の本体特性として再構成し、病機・用量・配伍へ接続します。

### [鍼灸・位相幾何](/ja/research/acupuncture/)
穴位を孤立した点ではなく、経脈上の相対位置、幾何役割、制御窓として検証します。

### [扁鵲鏡経](/ja/research/bianque-mirror/)
測定、符号化、座標、ネットワーク、観測、揆度、個体化を通じ、古代診断体系の構造を読み解きます。

## 読み方

各領域ページでは、上部に短い概要、その下に展開可能な全文ガイド、さらに現在の推奨順で並べた記事一覧があります。記事の実体ファイル名や歴史的番号ではなく、研究上の認知順序を基準に読み進められる構造です。
