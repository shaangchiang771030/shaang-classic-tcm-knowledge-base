## 为什么建立 Cosmos Order

古典医学留下了大量看似分散的语言：阴阳、五行、三阴三阳、六气、经络、五味、脉、方与时令。Cosmos Order 的工作不是再传播一次容易取得的中医常识，而是回到原典与结构，追问这些体系之间是否共享更深层、可反复检查的秩序。

我们把“天体周期与圆周运动是否构成多套古典模型的共同源头”视为一条核心研究命题，而不是预先宣告的科学结论；文本、模型、反例与资料验证会逐步决定它能走多远。

## Cosmos Order 的研究方向

**观察 → 抽象 → 建模 → 交叉验证 → 反例 → 应用。**

我们希望读者不只记住结论，而能逐步掌握古典知识如何被推导、在哪些地方仍有不确定性，以及它如何回到真实的人体与生活。
