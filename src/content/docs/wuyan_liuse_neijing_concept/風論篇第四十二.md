黃帝問曰：風之傷人也，或為<span class="c-cold">寒</span><span class="c-hot">熱</span>，或為<span class="c-hot">熱</span>中，或為<span class="c-cold">寒</span>中，或為癘風，或為偏枯，或為風也，其病各異，其名不同。或內至五臟六腑，不知其解，願聞其說。

<span class="model-tag">[陰陽－空間／人體]</span>

岐伯對曰：風氣藏在皮膚之間，<span class="c-yin">內</span>不得通，<span class="c-yang">外</span>不得洩。

風者，善行而數變，腠理開，則灑然<span class="c-cold">寒</span>，閉則<span class="c-hot">熱</span>而悶。其<span class="c-cold">寒</span>也，則<span class="c-cold">衰食飲</span>；其<span class="c-hot">熱</span>也，則<span class="c-hot">消肌肉</span>。故使人怢栗而不能食，名曰<span class="c-cold">寒</span><span class="c-hot">熱</span>。

風氣與<span class="c-yangming">陽明</span>入<span class="c-earth">胃</span>，循脈而上至目內眥，其人肥，則風氣不得<span class="c-yang">外</span>洩，則為<span class="c-hot">熱</span>中而目黃；人瘦則<span class="c-yang">外</span>洩而<span class="c-cold">寒</span>，則為<span class="c-cold">寒</span>中而泣出。

<span class="model-tag">[陰陽－空間／人體｜營衛]</span>

風氣與<span class="c-taiyang">太陽</span>俱入，行諸脈俞，散於分肉之間，與<span class="c-yang">衛氣</span>相乾，其道不利。故使肌肉憤（月真）而有瘍，<span class="c-yang">衛氣</span>有所凝而不行，故其肉有不仁也。

癘者，有<span class="c-yin">榮氣</span><span class="c-hot">熱</span>腑，其氣不清，故使其<span class="c-hot">鼻柱壞而色敗，皮膚瘍潰</span>。風<span class="c-cold">寒</span>客於脈而不去，名曰癘風，或名曰<span class="c-cold">寒</span><span class="c-hot">熱</span>。

<span class="model-tag">[五行－時間／年尺度]</span>
<span class="model-tag">[五行－時間／一組天干（十日）為週期]</span>
<span class="model-tag">[五行－空間／人體]</span>

<span class="model-map">以<span class="c-wood">春甲乙</span>傷於風者為<span class="c-wood">肝</span>風，以<span class="c-fire">夏丙丁</span>傷於風者為<span class="c-fire">心</span>風，以<span class="c-earth">季夏戊己</span>傷於邪者為<span class="c-earth">脾</span>風，以<span class="c-metal">秋庚辛</span>中於邪者為<span class="c-metal">肺</span>風，以<span class="c-water">冬壬癸</span>中於邪者為<span class="c-water">腎</span>風。</span>

風中五臟六腑之俞，亦為臟腑之風，各入其門戶，所中則為偏風。

風氣循風府而上，則為胸風，風入系頭，則為目風，眼寒。

飲酒中風，則為漏風。

入房汗出中風，則為內風。

新沐中風，則為首風。

久風入中，則為腸風，飧洩。

外在腠理，則為洩風。

故風者，百病之長也，至其變化，乃為他病也，無常方，然致有風氣也。

帝曰：五臟風之形狀不同者何？願聞其診，及其病能。

<span class="model-tag">[五行－空間／人體｜五臟風]</span>

岐伯曰：<span class="c-metal">肺</span>風之狀，<span class="c-jueyin">多汗、惡風</span>，色<span class="c-metal">皏然白</span>，時<span class="c-metal">咳短氣</span>，晝日則差，暮則甚，診在<span class="c-metal">眉上</span>，其色<span class="c-metal">白</span>。

<span class="c-fire">心</span>風之狀，<span class="c-jueyin">多汗、惡風</span>，<span class="c-fire">焦絕善怒嚇</span>，<span class="c-fire">赤</span>色，病甚則<span class="c-fire">言不可快</span>，診在<span class="c-fire">口</span>，其色<span class="c-fire">赤</span>。

<span class="c-wood">肝</span>風之狀，<span class="c-jueyin">多汗、惡風</span>，<span class="c-wood">善悲</span>，色<span class="c-wood">微蒼</span>，<span class="c-wood">噎乾善怒，時憎女子</span>，診在<span class="c-wood">目下</span>，其色<span class="c-wood">青</span>。

<span class="c-earth">脾</span>風之狀，<span class="c-jueyin">多汗、惡風</span>，<span class="c-earth">身體怠墮，四支不欲動</span>，色<span class="c-earth">薄微黃</span>，<span class="c-earth">不嗜食</span>，診在<span class="c-earth">鼻上</span>，其色<span class="c-earth">黃</span>。

<span class="c-water">腎</span>風之狀，<span class="c-jueyin">多汗、惡風</span>，<span class="c-water">面龐然浮腫，脊痛不能正立</span>，其色<span class="c-water">炲</span>，<span class="c-water">隱曲不利</span>，診在<span class="c-water">肌上</span>，其色<span class="c-water">黑</span>。

<span class="c-earth">胃</span>風之狀，頸<span class="c-jueyin">多汗</span>，<span class="c-jueyin">惡風</span>，<span class="c-earth">食飲不下，膈塞不通，腹善脹，失衣則（月真）脹</span>，食<span class="c-cold">寒</span>則<span class="c-earth">洩</span>，診<span class="c-earth">形瘦而腹大</span>。

首風之狀，頭面<span class="c-jueyin">多汗</span>，<span class="c-jueyin">惡風</span>、當先風一日，則病甚，頭痛不可以出內，至其風日，則病少愈。

漏風之狀，或<span class="c-jueyin">多汗</span>，常不可單衣，食則汗出，甚則身汗，喘息<span class="c-jueyin">惡風</span>，衣常濡，口乾善渴，不能勞事。

洩風之狀，<span class="c-jueyin">多汗</span>，汗出洩衣上，口中乾，上漬其風，不能勞事，身體盡痛，則寒。

帝曰：善。
