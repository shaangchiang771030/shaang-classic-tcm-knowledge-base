# 五顏六色解內經

## 一、此領域介紹

這個學習模塊的初始精神，很質樸.

就是整部內經，甚至是其它幾本超過兩千年的中醫經典.

它們的本質，都是陰陽五行的底層模型所構成以及衍生出不同層面的豐富世界.

在內經的素問與靈樞兩部中，較常用到的時空模型有27種左右. (請詳時空篇文章)

時空篇的立論，是由博返約，由162篇內經篇章，提取出的陰陽/五行/六氣/六淫/九宮.

五顏六色解內經的立論，則是由約返博.

我們將陰陽/五行/六氣/六淫等模型內的各個元素，以較直觀的顏色去做標定.

這樣，每個篇章，哪個段落，用到哪個時空模型，每個元素，又是由哪些詞來代表.

希望，在這樣符合老祖宗原意，但突破竹簡較難的描色限制之後.

能夠仗得內經篇章的結構，藉由五行與六氣/六淫的顏色，能夠浮現出來.

我們相信，如此則勝過千言萬語的循環注解.
