開・闔・枢は、六経を「六つの名称」から六つの動的機能へ変える。**開**は外へ出て布散すること、**闔**は内へ入り収納すること、**枢**は内外の転換を主る。

三陽では太陽が開、陽明が闔、少陽が枢。三陰では太陰が開、厥陰が闔、少陰が枢である。太陽は上行して外へ達し皮毛を守り、陽明は内行して下へ達し、少陽は内外の出入を担う。太陰は気血津液を布散し、厥陰は上下焦の陰血を蔵し、少陰は陰経内部の転枢を担う。

したがって開闔枢で重要なのは静的な部位ではなく、気機が **「開けず外へ出ないのか、闔じて内へ入れないのか、それとも枢転できないのか」** を判定することである。

開闔枢は図がないと想像しにくい。西洋で「生命の花」や二重トーラスとして知られる重なり格子は、幾何学的には少数の単純な作図規則から生成できる。本研究ではそれを、三次元で動的な陰陽太極体を考えるための視覚化として用いる。古典の六経が現代物理のトーラス場と文字どおり同一であることを証明するものではない。

![生命の花と二重トーラスの模式図](/images/qihua_physiology/生命之花.png)

| 六経 | 「生命の花」モデルにおける図像対応 |
| --- | --- |
| 太陽・開 | 最外球面、遠心的な発散 |
| 陽明・闔 | 内向きの漏斗、求心的な下降 |
| 少陽・枢 | 中央の腰・喉、S字曲線の転換点 |
| 太陰・開 | 白い魚眼から外への放射 |
| 厥陰・闔 | 黒い魚眼／最深部の特異点 |
| 少陰・枢 | 垂直中軸の水火柱 |

この幾何学的対照を置くと、次の経文も視覚的に理解しやすくなる。

> 帝曰く：「陽明とは何をいうか。」岐伯曰く：「二陽が合して明となる。」  
> 帝曰く：「厥陰とは何か。」岐伯曰く：「二陰が交わって尽きるところである。」

さらに桂林古本や傷寒鈐法における経方の変化数を見ると、開 > 闔 > 枢という比率に近い傾向も観察される。本研究では、これを幾何学から結論づけるのではなく、独立に検証すべきパターンとして扱う。

## 『医学探源』原文の現代語訳

「開闔は戸の扉のようなもので、枢は扉が回る軸である。枢がなければ開闔できず、開闔がなければ枢は回らない。ゆえに三者は失ってはならない。開は外へ出ることを主り、闔は内へ入ることを主り、枢は内外の間を主る。太陽膀胱の気化は上行して外へ達し、皮毛を満たして外を衛り固めるので、太陽は開を主る。……陽明胃経は水穀を納め……その気化は内行下達を主るため、陽明は闔を主る。……少陽三焦は内で膈膜、外で腠理を主り、内外出入の気は腠理を往来する。……三陽の気は形身の内外で開闔し、三陰の気は内部の前後上下で開闔する。……血脈の周流、津液の四達はみな太陰が司るので、太陰を開という。……厥陰を闔というのは、足厥陰肝経が下焦の陰気を蔵し、手厥陰心包絡が上焦の陰気を蔵するからである。……少陰を枢というのは、手少陰心経が内で包絡と合し、下で脾土を生じ、足少陰腎経が上で肺金を済け、下で肝木を生じるからである。……これらは審証施治の重大な鍵であり、詳しく究めなければならない。」
