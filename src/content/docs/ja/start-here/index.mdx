# はじめに

Cosmos Order では、すべての読者が同じ記事から始める必要はありません。内容は **基礎・発展・研究** の三段階に分けています。「基礎」は一般向けの簡略化という意味ではなく、その後の推論に必要な第一層のモデルを指します。

## 内容の深さ

- **基礎**：その領域に不可欠なモデルをつくります。
- **発展**：前提モデルを使い、複数の構造と推論を組み合わせます。
- **研究**：原典再構成、反例、モデル比較、検証、まだ閉じていない問題へ進みます。
