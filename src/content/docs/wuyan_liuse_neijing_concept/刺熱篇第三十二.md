<span class="model-tag">[五行－空間／人體｜五臟熱病]</span>
<span class="model-tag">[五行－時間／一組天干（十日）為週期]</span>
<span class="model-tag">[五行－空間（相克）]</span>

<span class="model-map"><span class="c-wood">肝</span><span class="c-hot">熱</span>病者，<span class="c-wood">小便先黃，腹痛多臥</span>，<span class="c-hot">身熱</span>。<span class="c-hot">熱</span>爭則<span class="c-wood">狂言及驚，脅滿痛，手足躁，不得安臥</span>。<span class="c-metal">庚辛</span>甚，<span class="c-wood">甲乙</span>大汗。氣逆則<span class="c-metal">庚辛</span>死。刺足<span class="c-jueyin">厥陰</span><span class="c-shaoyang">少陽</span>，其逆則<span class="c-wood">頭痛員員，脈引衝頭</span>也。

<span class="c-fire">心</span><span class="c-hot">熱</span>病者，<span class="c-fire">先不樂</span>，<span class="c-hot">數日乃熱</span>，<span class="c-hot">熱</span>爭則<span class="c-fire">卒心痛，煩悶善嘔，頭痛面赤，無汗</span>。<span class="c-water">壬癸</span>甚，<span class="c-fire">丙丁</span>大汗。氣逆則<span class="c-water">壬癸</span>死，刺手<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>。

<span class="c-earth">脾</span><span class="c-hot">熱</span>病者，<span class="c-earth">先頭重、頰痛、煩心、顏青、欲嘔</span>、<span class="c-hot">身熱</span>。<span class="c-hot">熱</span>爭則<span class="c-earth">腰痛，不可用俯仰，腹滿洩，兩頷痛</span>。<span class="c-wood">甲乙</span>甚，<span class="c-earth">戊己</span>大汗；氣逆則<span class="c-wood">甲乙</span>死，刺足<span class="c-taiyin">太陰</span><span class="c-yangming">陽明</span>。

<span class="c-metal">肺</span><span class="c-hot">熱</span>病者，<span class="c-metal">先淅然厥起毫毛，惡風</span><span class="c-cold">寒</span>，<span class="c-metal">舌上黃</span><span class="c-hot">身熱</span>。<span class="c-hot">熱</span>爭則<span class="c-metal">喘咳，痛走胸膺背，不得大息，頭痛不堪，汗出而</span><span class="c-cold">寒</span>。<span class="c-fire">丙丁</span>甚，<span class="c-metal">庚辛</span>大汗。氣逆則<span class="c-fire">丙丁</span>死。刺手<span class="c-taiyin">太陰</span><span class="c-yangming">陽明</span>，出血如大豆，立已。

<span class="c-water">腎</span><span class="c-hot">熱</span>病者，<span class="c-water">先腰痛胻酸，苦渴數飲</span><span class="c-hot">身熱</span>。<span class="c-hot">熱</span>爭則<span class="c-water">項痛而強，胻</span><span class="c-cold">寒</span><span class="c-water">且酸</span>，<span class="c-hot">足下熱</span>，<span class="c-water">不欲言</span>。其逆則<span class="c-water">項痛，員員淡淡然</span>。<span class="c-earth">戊己</span>甚，<span class="c-water">壬癸</span>大汗。氣逆則<span class="c-earth">戊己</span>死。刺足<span class="c-shaoyin">少陰</span><span class="c-taiyang">太陽</span>，諸汗者，至其所勝日汗出也。</span>

<span class="model-tag">[五行－空間／人體｜五臟面部映射]</span>

<span class="model-map"><span class="c-wood">肝</span><span class="c-hot">熱</span>病者，<span class="c-wood">左頰</span>先<span class="c-fire">赤</span>；<span class="c-fire">心</span><span class="c-hot">熱</span>病者，<span class="c-fire">顏</span>先<span class="c-fire">赤</span>；<span class="c-earth">脾</span><span class="c-hot">熱</span>病者，<span class="c-earth">鼻</span>先<span class="c-fire">赤</span>；<span class="c-metal">肺</span><span class="c-hot">熱</span>病者，<span class="c-metal">右頰</span>先<span class="c-fire">赤</span>；<span class="c-water">腎</span><span class="c-hot">熱</span>病，<span class="c-water">頤</span>先<span class="c-fire">赤</span>。</span>

病雖未發，見<span class="c-fire">赤色</span>者刺之，名曰治未病。

<span class="c-hot">熱病</span>從部所起者，至期而已，其刺之反者，三周而已。重逆則死。諸當汗者，至其所勝日，汗大出也。

諸治<span class="c-hot">熱病</span>，以飲之<span class="c-cold">寒水</span>乃刺之，必<span class="c-cold">寒</span>應之，居止<span class="c-cold">寒</span>處，身<span class="c-cold">寒</span>而止也。

<span class="model-tag">[三陰三陽－空間／人體]</span>

<span class="c-hot">熱病</span>先<span class="c-wood">胸脅痛</span>，手足躁，刺足<span class="c-shaoyang">少陽</span>，補足<span class="c-taiyin">太陰</span>。病甚者為五十九刺。

<span class="c-hot">熱病</span>始<span class="c-metal">手臂病</span>者，刺手<span class="c-yangming">陽明</span><span class="c-taiyin">太陰</span>而汗出止。

<span class="c-hot">熱病</span>始於<span class="c-taiyang">頭首</span>者，刺項<span class="c-taiyang">太陽</span>而汗出止。

<span class="c-hot">熱病</span>先<span class="c-water">身重骨痛、耳聾、好瞑</span>、刺足<span class="c-shaoyin">少陰</span>，病甚為五十九刺。

<span class="c-hot">熱病</span>先<span class="c-wood">眩冒而</span><span class="c-hot">熱</span><span class="c-wood">，胸脅滿</span>，刺足<span class="c-shaoyin">少陰</span><span class="c-shaoyang">少陽</span>。

<span class="model-tag">[三陰三陽－空間／人體｜脈色]</span>

<span class="c-taiyang">太陽</span>之脈色榮<span class="c-taiyang">顴骨</span>，<span class="c-hot">熱病</span>也。榮未交，曰今且得汗，待時而已。與<span class="c-jueyin">厥陰</span>脈爭見者，死期不過三日。

其<span class="c-hot">熱病</span>內連<span class="c-water">腎</span>，<span class="c-shaoyang">少陽</span>之脈色也。<span class="c-shaoyang">少陽</span>之脈色榮<span class="c-shaoyang">頰前</span>，<span class="c-hot">熱病</span>也。榮未交，曰今且得汗，待時而已。與<span class="c-shaoyin">少陰</span>脈爭見者，死期不過三日。

<span class="model-tag">[五行－空間／人體]</span>

<span class="c-hot">熱病</span>氣穴，三椎下間主<span class="c-metal">胸中熱</span>，四椎下間主<span class="c-fire">膈中熱</span>，五椎下間主<span class="c-wood">肝</span><span class="c-hot">熱</span>，六椎下間主<span class="c-earth">脾</span><span class="c-hot">熱</span>，七椎下間主<span class="c-water">腎</span><span class="c-hot">熱</span>。榮在骶也，項上三椎陷者中也。

頰下逆顴為大瘕；下牙車為腹滿；顴後為脅痛；頰上者膈上也。
